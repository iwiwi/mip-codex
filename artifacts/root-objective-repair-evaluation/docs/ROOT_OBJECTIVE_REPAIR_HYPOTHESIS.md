# 既存主解に目的上限制約を加える修復

根LP前の既存自作修復が発見した点だけを起点にする。純二値、目的係数が元入力で厳密1、定数0の構造を対象とし、暫定モデルに目的和≤既存主解−1を追加して既存のRust Repairを呼ぶ。候補は必ず元のRepairで再確認し、有限で厳密に良い元目的値だけを採用する。暫定制約の不能や修復失敗は大域不能・下界・最適性に使わない。元の主解は常に保持する。

5%の時間予算、最大0.5秒、各探索100M work、最大16回。開始点は選択変数0.95/未選択0.001とし、最初の丸めは元の整数点を保持、追加試行だけで小さな摂動を与える。モデル/Repair構築を含む実測時間を保存する。元問題のroot-seed修復が呼ばれなかった場合は対象外、既定無効でMIP_ROOT_OBJECTIVE_REPAIR=1により対照測定する。
