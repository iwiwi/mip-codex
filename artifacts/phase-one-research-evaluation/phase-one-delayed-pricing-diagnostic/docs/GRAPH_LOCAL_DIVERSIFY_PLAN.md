# 局所探索の再構築を多様化する

PR39で単に予算を増やしても主解が改善しなかった。現在は64反復改善しないと最良集合へ戻るが、追加の順番が常に同じなので似た局所領域を繰り返し得る。新案は最良集合へ戻る際、固定seedのFisher-Yates順で選択頂点の一部（集合サイズ/16、最低2、集合サイズ以下）を外し、その順に競合0の頂点を追加する。以後の追加も新しい順を使う。時間枠は全体5%・最大0.25秒、反復数は旧設定のまま。

MIP_GRAPH_LOCAL_DIVERSIFY=1で実験、既定無効。記録へ再構築数・外した頂点数を保存する。最良集合は全ペアの厳密検査後だけ更新し、上界や証明規則は変更しない。旧との15/60秒比較、内部全列挙、元MPS検査を行う。最良主解が悪化しないという保証は同じ試行列内だけであり、同じ期限で旧版より良いとは限らないため実測する。
