# 競合構造上の局所探索を採用

二値・一様目的・競合制約を元の係数から認識した場合だけ、初期集合へ1対2交換、1対1交換、少数頂点の摂動と貪欲追加を行う。最良集合を保存する前に全ペアを厳密に検査する。時間枠は全体の5%・最大0.25秒、固定乱数seedを使う。上界や枝刈りの数学は変更しない。MIP_GRAPH_LOCAL_SEARCH=0で無効化できる。

## 15秒の開発比較

各実行は1thread・16GiB。追加open入力はBenchmark v2全240問の成績に加算しない。既知値・解を探索へ渡さない。

sorrell7の局所探索は初期集合152個から187個へ改善し、追加3回もprimal-187/dual-449を再現した。局所探索の所要時間は約0.250秒、厳密検査失敗0。sorrell3は14個から16個へ改善し、約0.071秒だった。探索領域と節点数が変わるため、節点数から速度改善は主張しない。最初の主解時刻は初期貪欲解の時刻であり、最終局所探索解の発見時刻ではない。

sorrell7の公式掲載値-198には届かず、HiGHSの下界は本実装より強い。一つの追加入力の主解改善で全体優位は主張しない。公式掲載値の確認と入力出典はGRAPH_DEADLINE_RESULTS.mdおよびexperiments/sorrell7-input-20261115.jsonを参照。
