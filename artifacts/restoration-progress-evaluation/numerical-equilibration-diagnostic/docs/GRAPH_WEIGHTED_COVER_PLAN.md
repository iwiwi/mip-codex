# 二値競合グラフの重み付き頂点被覆局所探索

2026-11-15。既存の汎用binary packing認識で得た競合グラフに限り、被覆の補集合を実行可能独立集合として探索する。辺重み、2段階の除去/追加、近傍変化による再追加制御、古い重みの減衰を独自Rustで実装する。全ての更新候補は元のcompatible graphで全組対検査し、上界/証明木は変更しない。

参考：Cai/Su/Luo/Sattar, NuMVC, JAIR46 (2013), DOI 10.1613/jair.3907、著者論文 https://arxiv.org/abs/1402.0584 、著者の書誌 https://lcs.ios.ac.cn/~caisw/VC.html （2026-11-15閲覧）。既存のコードは読まず/コピーせず、数学的方法のみ参照。全入力共通の重み忘却は平均重み0.5*nで3/10へ整数切捨て。論文の問題別例外設定は使わない。

試作はMIP_GRAPH_COVER_LOCAL、既定無効。既存local予算（5%、最大2秒）の20%を元の局所探索、残りを本探索へ割り当て、最大128*nかつ500000交換。グラフから辺を作るメモリも既存workspace上限で制限し、期限を確認する。問題名/既知解/答えをコードへ使わない。

検証は小グラフ全列挙、各操作のスコア/未被覆辺集合の再計算、元MPS点/graph証明の独立検査。開発用sorrell3/7の15/60秒と固定開発18問を比較し、速度と主解品質の回帰を記録する。未知検証用問題を調整に用いない。

初期版：sorrell7は15秒-191→-193、60秒-195（dual-379不変）。sorrell3は16/同じ6042153証明節点だがMVCで約0.52秒追加。次は最初の16*n交換で初期bestを更新できない場合に打切り、更新できた場合は時間予算内で最大1024*n/2000000交換を許す。初期iteration capにより60秒では2秒枠を使い切らず262144回で停止していた。

実験の手順失敗：汎用smokeでBenchmark v2外のsorrell7を指定してKeyErrorになったため、初期S3部分結果と失敗ログを保持し、探索用入力のラベルを分けた専用スクリプトへ切替えた。最初のbinary全列挙は出力先の指定を忘れたため、生成後のdefault出力をgraph-cover-initial-default-enumerationへコピー保存し、一意出力先で再実行した。以前の試行は既存の各evaluation archiveに保持されている。

初期16*nで改善が無ければ打切る案は、60秒配分/0探索節点の診断でsorrell7を-191のまま止め、初期版-195より悪化したため不採用。低予算での即時改善はこの探索の有用性を十分に予測しなかった。候補数/打切りを初期128*n/500000へ戻し、sorrell3の約0.52秒追加という代償も明示して品質改善を評価する。別の時間配分の検討は採用版を確定した後に行う。
