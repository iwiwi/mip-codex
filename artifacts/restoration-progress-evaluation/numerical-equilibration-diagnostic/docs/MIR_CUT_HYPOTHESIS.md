# 次の仮説：連続項を残す混合整数丸め

既存CG丸めは、保持できない変数を元の有限境界で投影する。非負continuous項を残すMIRを検討する。数学的な通常形はSCIP公式の[関数ドキュメント](https://scipopt.org/doc-10.0.2/html/cuts_8c.php)にあるMIR定義を参照する。外部実装コードの移植・外部最適化呼出しは行わない。

最初は整数係数/整数右辺の元行と、厳密整数の元境界だけを使う。変数を下限からの差または上限からの差として非負に変換し、正整数dで割る。変換後右辺bにr=b mod d、h=d−r、r≠0とする。通常のMIR式をh倍すると、保持する整数項aの係数は

`h * floor(a/d) + max((a mod d) − r, 0)`

となる。continuous係数は負なら元のa、非負なら0、右辺は`h * floor(b/d)`。元変数へ戻した係数/右辺も整数として計算する。この整数形は通常形からの代数変形であり、標準MIRの新しい定理を主張しない。checked i128で計算し、f64に厳密に載る範囲だけを出す。非負化できない自由変数、非整数境界、overflow等は候補を棄却する。

まず保存済み開発根点で候補を診断し、元行からPython Fractionで独立再計算する。整数変数の全列挙と、continuous2変数のbox/元行との交点を全て検査すれば、固定整数値ごとの連続多角形全体での安全性も確認できる。偽証明・符号・bound向き・負RHS/divisionも検査する。下界改善がなければ、Rust実装を先に増やさず記録する。

採用するならProofに境界の向きとdivisorを保存し、Rust/Python両方で元MPSの証明を検査する。最初は元1行だけとし、子節点boundや切断の循環参照を使わない。候補数/仕事/時間を制限し、既存aggregateとの枠配分は別に比較する。native LPは比較だけで、点/乗数はRustへ返さない。
