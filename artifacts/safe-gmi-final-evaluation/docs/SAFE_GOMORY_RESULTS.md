# GMI下界の報告

最終候補はFP04a5bfb314092d16。親main PR104の根LPからGMIを別計算し、元データと有効カットに対する外向きLagrangian検証が成立した下界を報告へ加える。探索用のモデル・LP結果・基底へ戻し、枝刈りと最適判定は従来の探索下界を使う。`MIP_GOMORY_CUTS=0`で無効。既定は`gomory_cuts=true, gomory_report_only=true`。探索行列へ入れる版は実験設定であり採用判断の対象外。

近似BTRANは候補提案だけに使う。元の厳密整数係数・辺・変数anchorからchecked i128でGMIを再導出し、2の冪による同値縮尺で係数を整える。元行・整数乗数・complement・pivotを証明に残す。報告下界の乗数はbinary64のbit列、不足する変数境界は元行からの外向き導出手順を保存。独立Python/Fraction検査器が元MPSからカット・境界導出・Lagrangian値を再構築する。候補16行×変数数100万以下、元非零係数100万以下、5%/最大1秒の根予算。原問題の許容誤差は変えていない。
