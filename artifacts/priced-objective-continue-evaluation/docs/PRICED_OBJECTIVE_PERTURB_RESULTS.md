# 目的cut修復の摂動量診断（不採用）

継続案の自作60秒整数点だけをseedに、既存Repairへ渡すselected/unselected確率を共通の4組で比較した。全設定2秒、CPU42、同一helper。ソース/ELF/SHAを実行前固定し、library FP6aa6bb56ffcb27e3の全sourceを参照する。元モデルで改善だけを受理し、追加2秒の独立診断であって主ソルバー全体2秒比較ではない。

SP97 seed838597508.8に対し、既存(.95,.001)は813099308.48、(.8,.001)は837321567.04、(.95,.005)/(.8,.005)は元点同値。SP98 seed658266817.76は4設定すべて同値。強い摂動は既存設定より良い点を得なかったため採用しない。8点の元MPS独立監査を継続する。モデル名・既知値を条件にした設定はソルバーへ加えない。

8点すべて元MPSのGMP絶対・公式検査有効。品質改善不足のため不採用で確定する。
