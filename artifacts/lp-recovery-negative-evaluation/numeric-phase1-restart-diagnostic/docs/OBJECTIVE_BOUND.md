# 原目的からの保証下界

独自Rust LPの行乗数を候補として、元十進係数を包含する区間でLagrangian下界を再計算する。有限箱のreduced costの最小値を足すため、乗数のdual feasibilityを前提にしない。非有界方向で符号を証明できなければ採用しない。point係数の曖昧な打消しだけは整数limbによる厳密積和を使う。通常の浮動小数LP下界とは別の追加下界であり、探索全体を厳密算術化する変更ではない。

原integer属性と、厳密整数等式の唯一の未確定変数が係数±1であるという推論から、費用に現れる変数の整数性を証明する。整数費用のgcdで目的値latticeを求める。有限原境界から目的をbase+非負整数増分へ変形できれば、baseより大きい値の最小増分も使う。min/maxを区別し、外向き引算・除算とi128計算で安全に丸める。範囲外・不明なmetadata・非整数境界・伝播有効・dense engineでは追加機能を省く。

`MIP_OBJECTIVE_ROUNDING=0`は無効、`1`は根限定、`all`は全ノードの任意実験設定。全ノード版はmarkshareの60秒比較で31.115秒から33.847秒へ悪化したため既定にしない。根限定では根後に証明用cacheを捨てる。保証下界は子に継承し、箱の目的最大値がそれを下回れば枝刈りする。主解候補の目的が保証値より小さければ拒否する。整数許容誤差が微小な必要分枝を隠す場合は厳密に分数の変数で分枝する。

Python Fraction検査器は元MPSから費用・offset・推論行・gcd・base・最小増分を再計算する。cutが0本、主解なしでも検査する。返却した解は別途GMP絶対検査と公式checkerで原問題へ照合する。任意乗数の1000件独立有理数fixtureと、min/maxの全列挙で下界を検証する。外部検査器は構造証明を検査し、全探索のLP下界証明書を検査するものではない。

根cutの上限も明示した。従来の4回ではコード高速化で時間枠内に3回目のcutが入り、binkarの主解が6794.860025から7394.229988へ悪化した。4対2の18問対照では他17問同等で、2回なら6794.860025へ戻ったため2を採用する。目的下界を無効にした対照でも起きる現象である。失敗した候補・誤ったテストfixture・対照結果をartifactsとJOURNALに保存する。
