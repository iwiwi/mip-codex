# 厳密な二値等式によるLP列共有

親main PR104。開発188例の読取専用構造調査では32例に二値x=yの厳密元等式がある。列を共有して等式行を除去すれば、根LPの次元と退化を減らせる可能性がある。最適化処理は自作Rustのまま。MIP_BINARY_EQUALITY_COLUMNS既定false、実験のみ。問題名や既知解は参照しない。

元の上下境界が厳密0/1で整数、行の両辺が厳密0、係数が厳密整数aと-aである2変数等式だけをunion-findで結ぶ。各候補成分は全ての目的係数と接続行係数が厳密整数で、成分の絶対和が2^52以下の場合のみ採用し、全加算を表現可能にする。100万変数/1000万係数と5%/最大0.25秒の構築上限。各Standardでは同じ元変数群のboundsを交差し、同一shift/列へ写す。異なる枝境界の衝突は厳密元等式と整数boundsからの矛盾。余剰行は証明に用いたx=yだけを削除。追加カットによる列合算が正確でなければ、そのLPでは元の列配置へfallbackする。

全変数のtermsを保持して主解とrayを元空間へ戻し、元モデルの検査を保つ。warm互換性・LP証明チェックも変更しない。探索Modelそのものの行/変数は削除せず、元データとカットの証明番号を保つ。追加の目的格子下界検証では元等式乗数を再構築しないため、証明が弱くなる可能性も評価する。
