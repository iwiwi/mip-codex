# 純二値競合の構造認識と彩色上界

全変数が元境界で0/1、目的係数が同じ厳密整数で、全行が正の整数係数による「高々1個」の制約または冗長行と証明できる場合だけ、独立集合へ変換する。補グラフのクリークをbitsetで探索し、各候補集合の正しい貪欲彩色数を上界にする。問題名・既知解には依存しない。未対応構造は通常のRust LP/MILPへ戻す。

初版は4096変数まで。元行の単独選択がすべて可能で、任意の2個が不可能という条件を係数/RHSの元データ区間で検証する。未知の精度、重み付き非一様目的、負の係数、非冗長な下側制約は受理しない。認識はモデル全体を検査してから探索する。

彩色された候補prefixはその色数より大きいクリークを含まない。逆順に候補を分岐し、選択頂点と隣接しない候補を除く。中断した彩色を枝刈りに使わない。中断時は完成済みの根彩色（なければ変数数）の上界を保持し、全探索完了と実行可能解を区別する。

参考（数学的原理・実装上の論点のみ、コード移植なし）: Patrick Prosser, Exact Algorithms for Maximum Clique: A Computational Study, Algorithms 2012, doi:10.3390/a5040545, https://www.mdpi.com/1999-4893/5/4/545 。彩色とbitsetを用いる原理は自作Rustへ独立に実装する。新たな最適化ライブラリは使わない。

まず全列挙のランダム小グラフ、拒否すべきMPS構造、制限時の上下界を検査する。その後MIP_BINARY_GRAPH=1（既定無効）で開発問題とnativeを比較する。LP前の箱主解と従来LPはmainの状態を維持する。

初回sorrell3は全行が負係数の下側制約（-x-y>=-1）で初版の認識外だった。各行の符号を一様反転できる場合も検査する。初回のLP fallback記録を残し、認識後の測定と混ぜない。

完成した根分岐を除いた候補prefixの色数を、残りの全体上界として更新する。根彩色だけの独立証明と、完了した分岐を前提にした探索進捗の上界を区別して記録する。節点制限0/1/2/3/7/無制限を小問題の全列挙で検査する。

sorrell3で旧LPの主解-14・下界なしから、15秒で-16・内部探索の下界-28へ改善（根彩色だけなら-36）。固定18問はすべてprimal/dual同一。最終検査後に既定有効化し、未認識構造は元のLPへ戻す。Box/他の機能の単体比較ではMIP_BINARY_GRAPH=0で条件を固定する。
