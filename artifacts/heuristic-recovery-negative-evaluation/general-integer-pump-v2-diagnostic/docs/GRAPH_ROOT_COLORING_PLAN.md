# 根彩色の候補比較

根だけに二つの別の正しい彩色を試す。競合グラフの共通近傍を多く残す色クラス構築と、互換グラフの飽和次数による彩色をRustで独立実装する。深い節点の高速な既存彩色は維持する。旧根彩色より色数が少ない完成候補だけを採用する。全体5%・最大0.15秒の枠を設け、途中候補は破棄する。

各色クラスは互換グラフの独立集合である。採用後の順序を(color,元の次数順位)で整列し、既存の独立検査器が再構成する根prefixと一致させる。上界を良くしても探索順の変化で主解品質が悪化し得るため、固定開発18問、sorrell3/別枠sorrell7で品質と時間を比較する。既定無効、MIP_GRAPH_ROOT_COLORING=1で試す。

Python試作では根色数sorrell3は旧36/共通近傍43/飽和次数31、sorrell7は449/379/391。これは最終性能の根拠ではなく実験仮説である。既知値や解は使用しない。

付随修正: smoke設定確認の辞書キーが複数文字列tupleへ誤変換されていた。個別キーへ戻し、明示BOX/BINARY/LOCAL=1の0秒実行で正常終了を確認した。以前の局所探索ベンチマークはBOX/BINARY環境変数が未設定なので当該assertを通らず、比較の算術結果には影響しない。

18:08 UTC追記: 候補の同点を元頂点番号と次数で固定し、試作Pythonと同じ選択に整理。Rustでもsorrell3の候補43/31、sorrell7の379/391を再現した。15秒比較の主解は-16/-187を維持、下界はsorrell3 -24で同じ、sorrell7 -449→-379。候補構築は約0.010/0.039秒。最終1200 CLI全列挙/3600偽証明拒否は成功した。

実行管理上の失敗も保存する。graph-root-before-smoke*は途中のバイナリ再ビルドをSHA検査が検出し終了1。後続のgraph-root-tie-*smokeは前段のafter実行とCPU3/4で重複したため、速度評価から除外する。正式な短期比較はgraph-root-final-*smokeのCPU5/6で新旧を順に実行し、バイナリを変更しない。全件native snapshotは不変で影響なし。
