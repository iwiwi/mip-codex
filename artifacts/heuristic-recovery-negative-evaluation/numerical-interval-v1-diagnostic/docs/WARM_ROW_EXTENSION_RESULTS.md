# 不等式行追加の基底再利用

元の目的係数・元列数・旧行係数・旧行種別・旧slack上限が厳密一致し、不等式のみ追加された場合に、旧基底へ新slackを追加する。旧内部列のslack/人工列は混在しているため、追加slackは内部列末尾に置き、旧人工列番号を変更しない。親のArc構造・基底・因子・cacheは変更しない。新しいblock下三角基底を疎LUで再分解し、既存の有界双対法で再最適化する。条件不一致、分解失敗、通常の数値失敗では従来のcold経路へ戻る。係数・許容誤差・不能証明検査は変更しない。

Rust192テスト成功。追加行で最適値が変わる例、人工変数が基底に残る例、親/兄弟の不変性、再度の行追加、不能な追加行、旧構造/費用/新等式の棄却、期限切れを検査した。200モデル×4追加のwarm/cold比較も成功。
