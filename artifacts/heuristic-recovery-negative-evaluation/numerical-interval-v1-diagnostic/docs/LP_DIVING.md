# 予算付き根LP潜り

一般的な主解ヒューリスティックであり、既存の最適化実装には委譲しない。根LPの点とRust疎LPのwarm基底から、整数に最も近いfractional変数を選び、近い整数側へ境界を絞って再最適化する。現在整数の変数も局所的に固定し、再最適化で再び分数化することを抑える。選んだ側が局所的に実行不能なら、同じ親の反対側を一度だけ試す。両側が失敗したら主解探索を終了する。

256局所LP、各4096pivot、壁時計は全体制限5%または0.25秒の小さい方。既存の丸め・連続部分修復を先に行い、その後で潜る。時間・pivot・メモリ制限や数値異常は局所探索の失敗だけにする。LP構築と検査のため壁時計にわずかな超過はあり得るが、LPには全体/局所期限を渡す。

整数を丸めた候補を元Modelの境界・整数性・制約で検査し、行の外向き区間でも確認する。採用は主解更新だけ。局所LPの下界・実行不能・非有界・数値異常を本体の探索木や擬似コスト、最適/実行不能宣言へ反映しない。全LP数に局所LPも含め、divingのcalls/lp_solves/reversals/infeasible/numerical_errors/limited/candidates/improvements/secondsを別記する。

CLIはMIP_LP_DIVING=0/1、既定有効、対象はrevisedエンジン。問題名や既知の答えによる調整はない。実装はc58d292、比較前の整数固定版は29f548e。
