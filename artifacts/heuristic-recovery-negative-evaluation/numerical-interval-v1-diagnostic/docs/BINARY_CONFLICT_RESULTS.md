# 純二値競合のRust彩色探索を採用

0/1変数・同一の厳密整数目的係数・全行が「高々1個」の競合または冗長行と証明できる場合だけ、補グラフのクリークをbitsetで探索する。全て負の係数の下側行も符号反転で扱う。係数と境界の元データ区間を使い、未知精度・非一様目的・混合符号などは通常のRust LPへ戻す。4096変数/展開ペア1000万/作業領域を上限とし、名前で分岐しない。既定有効、MIP_BINARY_GRAPH=0で無効化できる。

## 結果と限界

sorrell3を1thread/16GiB/15秒で比較した。旧LP経路は主解-14・下界なし、新経路は主解-16・下界-28。最終版3反復でも全回このprimal/dualとなった。固定開発18問は全てprimal/dual/statusが同じで、新経路には認識されなかった。

同じ15秒のnative短期比較（前PRの保存データ）はHiGHS primal/dual=-15/-20、SCIP=-11/-225、GLPK=-1/-512。新経路の主解はこの単例で良いが、HiGHSの下界には届かない。全体の優位は未評価。公式MIPLIB掲載値-16には一致したが、Rustのstatusはtime_limitであり最適性は未証明。既知値は評価文書だけで使い、ソルバーへ入力していない。
出典: https://miplib.zib.de/instance_details_sorrell3.html （2026-11-15確認）。

根の彩色は36色。逆順の根分岐を完了した分だけ残りprefixを更新し、15秒時点で82～83根分岐を完了、残り上界28を得た。根の36色は元MPSから独立に検査する。28は完了した分岐を前提とした内部探索の上界で、独立検査器は全探索木を再生していない。この区別をproof metadataへ保存する。候補prefixの色数・制限時の上下界は全列挙で検査した。

## 検証と再現

最終既定版は161Rustテスト。Rust内300グラフ×6節点制限の1800探索、CLI200モデル×6制限の1200実行を全列挙と照合した。全完了時の最適値と、未完了時の上下界が一致。元MPSのGMP/根彩色のFraction検査も成功し、3600件の偽bound/順列/辺数を拒否した。最終CLI cohortは整数目的係数と1/8刻みの目的定数、正/負行、min/maxを含む。同じ200例の反復と、最終の異なる生成recipeを独立な巨大試験数として膨らませない。

既存合成2700、根LP300、数値回帰32も成功。新経路/反復/CPU変更/診断/profileで出力した41解はGMP絶対・公式検査で全有効、134cuts/51証明記録も成功。全木の最適性を独立証明したという意味ではない。

初回sorrell3は負係数の下側行が認識外でLPへ戻った。診断runも保存し、符号反転対応後と区別する。既定変更で伝播などの機能別比較がgraphへ分岐したため、その比較ではbinary_graph=falseを指定して条件を固定した。失敗ログも保持し、最終161件は合格。

参考原理: Patrick Prosser, Algorithms 2012, doi:10.3390/a5040545, https://www.mdpi.com/1999-4893/5/4/545 。コード移植はせず、彩色上界とbitset探索を独立に実装した。

全データはartifacts/binary-graph-evaluation、移動hash台帳あり。不変snapshotはexperiments/binary-graph-snapshot-20261115.json、7831746b/FP35334a1a1e6dc75d/SHA0f3e2a3febdb7e63e40f7ac4177a96b44d61616da5e2b8e1e7f6d4876818c993。create-onlyで、全件Rust測定はまだ未開始。

5秒のperf診断547sample（lost0）では時計取得が約31.99%、主にcolor内の頂点ごとのInstant::nowだった。profile点も独立検査済み。次は時計確認の頻度を減らし、同じ固定節点数で結果を維持したまま速度が改善するか検査する。
