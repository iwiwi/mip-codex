# LP不可行証明の整数乗数候補

2026-11-15。glass4の標準LPでは、上限のないflow列の200*y1と500*y2等が±1.11e-14の残差を残し、元単位の不可行証明が保証できなかった。有限箱推論もこの列には効かない。

正/負それぞれの最大絶対乗数の小さい方（片符号ならその最大）をanchorとして比を取り、Rust独自の連分数で分母上限16/256/4096/65536の候補を作る。共通分母を払い、全要素が2^52以下の正確に表現可能な整数になる場合だけ既存の外向きcontradictionへ渡す。通常証明の失敗時だけ試し、各上限の前に期限を確認する。

候補生成の近似は信用しない。既存の標準LP証明検査を通った場合だけInfeasibleと新しいwitnessを返し、元小数問題の検査が必要ならmainのCertifierも引き続き通す。失敗した候補は従来どおり数値失敗扱い。LPのphaseI/ピボットや許容値は変更しない。raw比較はmain51の凍結snapshotをハッシュ照合して使う。

予備比較glass4：主解なし/92節点/0.103秒numerical_errorから、163節点/0.775秒で主解3466706233.3333354を得た（GMP/公式検査成功）。証明補完40件、その後別の数値失敗は残る。app1-1は元の59節点失敗のまま。固定開発18問、2700合成/300根LP/32数値、保存点の再検査とnative同資源比較を行う。未知検証用問題での調整はしない。
