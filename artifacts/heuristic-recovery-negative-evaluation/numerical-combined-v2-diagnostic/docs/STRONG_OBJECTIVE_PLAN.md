# 根強分枝の候補と実行不能hint

PR21のpumpは通常18問の主解/下界を改善せず、常時目的優先の摂動は隔離合成を悪化させたため未マージで閉じた。branch/全失敗は保存。目的だけへ探索を偏らせず、既存の分数度候補を残す。

現在の根強分枝は分数度上位8の両子LPを自作warm単体法で短く解き、両方optimalの場合だけlog gain積で順位を付ける。非零費用を持つ分数変数が少数で分数度が小さいと、候補へ入らないことがある。

候補変更: 分数度上位6とabs(cost)×分数距離の上位2の和集合を8まで補完する。最初の分数候補と最初の目的候補を交互に置き、時間制限内にも両方を試す。元の候補だけの設定を維持する。

別変更: 子の実行不能を高い選択スコアのhintにできるようにする。反対の子が予算切れでも順位を付けるが、mainへbound/主解/実行不能証明は採用しない。両子実行不能でも親は必ず通常の探索を続け、親node_limitのままの回帰を検査する。

2設定を分けて0/0、1/0、0/1、1/1の4モードで18開発問を同条件比較する。初期既定は両方false。8候補・両子256pivot・全体5%/最大.1秒は維持。全小例の最適値/実行不能を全列挙/HiGHSへ照合し、原MPSの主解をGMP/公式で検査する。採用前に利益/悪化/時間/失敗を併記する。
