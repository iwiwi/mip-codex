# LP不能証明の同時乗数摂動

2026-11-15仮説：未設定の上限を持つ列のFarkas残差が浮動小数/元小数係数の区間誤差でゼロをまたぐ。単独乗数の変更では複数列の符号を同時に直せない。

最大絶対値の8乗数に、相対±2^-32の全符号組合せを適用し、両方の全体符号を試す。最大512候補。候補生成は証明ではない。各候補で既存Certifier.boundの元係数/境界の外向き区間演算を全て通し、正の下界の場合だけ不能を受理する。それ以外は既存の保留処理と継承下界を維持する。既定無効の比較用環境変数MIP_JOINT_INFEASIBILITYを追加。

最初のgen-ip002保存失敗（node-proof-boxブランチ9b358c01のdump）では7候補目に下界1.5563154424754655を保証。節点の有限箱追加推論は17個の上限を一つも補えず不採用。その試作、dump、実行receiptは同ブランチに保存した。

検証：同CPU/資源10/60秒の有効無効比較、固定開発18問、小MILP全列挙/HiGHS比較、LP比較、数値回帰、保存された実行可能解と切除平面証明の独立検査。未知検証用問題で調整しない。最適性/不能の改善と主解発見の改善を区別する。
