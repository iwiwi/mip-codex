# 制約の非負結合から証明用の有限箱を導く

2026-11-15。各行の有限な上側（上側がなければ下側を反転）を足す。上限がない変数の係数が非正、または下限がない変数の係数が非負であれば、該当列へ適した符号を持つ行を非負重みで追加して符号改善を試す。最大8回。任意の有限な非負重みは有効な行結合なので、候補生成の算術誤差自体を信用する必要はない。

結合係数/右辺は元係数の区間を用いて全て外向き計算する。全寄与の下界を導けた場合だけ、既存と同じ区間差/除算で欠けた変数境界を補う。推論中に失敗した候補は箱を変更しない。証明器内部の根問題箱に限り利用し、LP探索や節点分枝境界には反映しない。最終不能判定は引き続き元問題のCertifier.bound>0に限定する。

保存20失敗節点では全41上限が有限になり、両符号を確認すれば全20個が区間証明可能となった。最初の診断は一方の符号だけをassertしたため12個目で失敗。両符号のログ/結果を残して再確認した。

試作は既定無効、MIP_AGGREGATE_INFEASIBILITY=0/1で比較する。gen-ip002の10/60秒、固定開発18問、小規模合成/LP/数値回帰、元問題での点・切除平面再検査を行い、解品質/不能証明/数値失敗改善を分けて記録する。未知検証用問題では調整しない。
