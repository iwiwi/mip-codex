# 彩色と主解の次の仮説

## 2026-11-15 18:10 UTC

根の彩色強化の次に、深い節点の彩色修復を候補とする。頂点vが色クラスiと1頂点wだけで隣接し、wを別の既存色クラスjへ移しても隣接がなければ、vをiへ移せる。クラスの独立性を各操作で維持し、完成クラスを色順へ並べてprefix boundを作る。候補を完全に構成できない場合は元の完成彩色へ戻す。既知解・問題名は不要。

理論出典はProsser 2012, Exact Algorithms for Maximum Clique: A Computational Study, https://www.mdpi.com/1999-4893/5/4/545, section2.3/4.1（2026-11-15再確認）。数式上の仕組みを参照し、掲載Java等のコードは移植しない。同研究は修復で節点が減っても計算時間が悪化する場合を報告しているため、節点数だけで採用しない。まず独自Rustのbitset版を既定無効で試し、全列挙・根証明・同時間品質・同作業時間で検証する。全面修復より、枝刈りに必要な色数を超える場合に限る方が費用を抑え得る。

別の候補は局所探索の試行回数/時間枠。sorrell7は15秒から60秒へ伸ばしても主解-187が不変で、現在の初期局所探索の枠が固定最大0.25秒であることが原因の一つかもしれない。摂動の探索幅や2対3交換も仮説とする。既知値へ達する回数をハードコードせず、全体時間に対する一般的な比率で比較し、sorrell3の証明探索を悪化させる費用も記録する。
