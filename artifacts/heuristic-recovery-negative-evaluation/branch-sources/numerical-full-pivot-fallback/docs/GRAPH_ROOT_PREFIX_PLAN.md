# 探索順を保つ複数彩色のprefix上界

PR38のsorrell7根上界449→379は有効だったが、追加60秒比較でsorrell3は根順の変更により18.336秒/6042153節点→20.633秒/6777969節点となった。PR39の局所探索予算増加は不採用。ここでは元の根彩色による探索順を固定し、完成した全彩色を各prefixへ制限した色の種類数の最小値を上界とする。

任意の彩色を頂点部分集合に制限しても正しい彩色であり、cliqueの大きさはその色数以下になる。複数の正しい上界の最小値も上界である。各prefixの色数は単調非減少なので逆順B&Bの条件も維持する。根の探索順・全候補彩色を結果へ保存し、独立Fraction検査器が元MPSの競合から全彩色と残prefix上界を再検査する。ただし完了済み根分岐の探索木自体は全再生しない。

既定無効、MIP_GRAPH_ROOT_PREFIX=1で試す。内部300グラフ×6節点制限×局所探索有無×根彩色有無×prefix有無=14400実行の全列挙、CLIの破損候補彩色/順列/残上界の拒否、同条件15/60秒の主解・下界・証明時間を検査する。既知値や問題名は最適化に使わない。
