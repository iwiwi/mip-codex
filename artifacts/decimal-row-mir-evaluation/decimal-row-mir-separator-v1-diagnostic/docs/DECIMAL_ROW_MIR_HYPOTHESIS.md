# 元の十進行を厳密整数倍してMIRへ渡す

現在のMIRは原MPSの小さい整数行に限定し、十進小数を含む行では候補を作らない。parserには既に非整数係数の元トークンが残る。これを使い、係数/RHS/RANGESのすべてが共通10冪（上限10^9）倍で2^52以下の整数に厳密変換できる行だけ、検証済みの倍率を記録する。元のRow係数/境界/誤差区間/exact_integralは変えない。

MIR証明に行倍率を追加し、Rustはparserの厳密メタデータと一致する場合だけ整数倍した行から既存i128導出を行う。Python Fraction checkerは元MPSの真の十進数を同じ倍率で掛けて整数性を直接検査する。係数と境界を単にfloat丸めして整数と見なさない。重複係数は元十進値を合計し、RANGES由来の上下側も元値で検査する。倍率が大きすぎる/整数化できない/overflowの場合は従来通り対象外。

まずparserと証明形式、小例と改ざん拒否を実装する。その後保存した開発LP点で候補の原MPS証明を検査し、有望なら既存MIR試行保持機構へ統合する。原点/主解/誤差許容差は変えず、holdoutは使わない。数値回復FP8bの188比較と3行集約FPddf7の60秒比較は凍結版で継続し、新機能を混ぜない。
