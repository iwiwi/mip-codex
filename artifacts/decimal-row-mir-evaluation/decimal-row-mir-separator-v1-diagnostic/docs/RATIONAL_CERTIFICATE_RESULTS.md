# 整数乗数候補で元単位のLP不能証明を補完

通常の元単位Farkas検査が失敗した場合だけ、乗数比の小分母連分数近似から共通分母を払った整数候補を作る。全要素は2^52以下の正確な整数に限定し、分母上限16/256/4096/65536を試す。候補の近似が正しいとは仮定せず、既存の外向きcontradiction(p,y)で元標準LPの不能を確認できた候補だけ採用する。必要な元小数MPSのCertifier検査も省略しない。

LP phaseI/ピボット/許容値は変えていない。連分数生成は全て独自Rust、既存最適化ライブラリへ委譲しない。通常検査が成功すれば呼ばず、各分母上限の前に期限を確認する。整数候補のサイズ超過や失敗は従来の数値失敗へ戻る。lp_certificate_repair_trials/repairsで件数を保存し、子の探索統計も集計する。
