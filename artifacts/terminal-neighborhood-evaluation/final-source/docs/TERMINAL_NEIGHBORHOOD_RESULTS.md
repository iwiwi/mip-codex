# 数値停止後の主解近傍探索

## 採用理由

元の探索が数値停止し有効主解を持つ場合だけ、残り時間（最大10秒）で最大16近傍を探索する。各近傍は整数変数の20/40/60/80%を決定的に解放し、最大1秒・1024節点・4096 pivotで自作Rust B&Bを使う。元問題で検査した有限の厳密な改善だけを採用し、従来の有効主解を保持する。局所の下界・証明・終了状態は大域に戻さず、数値停止を保持する。子呼び出しのrins=falseで再帰を防ぐ。最終候補はLimits.terminal_neighborhood=trueが既定、CLI MIP_TERMINAL_NEIGHBORHOOD=0/1で比較可能。rins=falseの場合も無効。
