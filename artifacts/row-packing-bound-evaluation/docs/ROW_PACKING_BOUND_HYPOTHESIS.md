# 非交差な単位被覆行の報告下界

元変数の下限が厳密0、最小化向きに正規化した全目的係数が厳密1である場合を対象とする。係数が全て厳密1、下側定数が厳密1の行を、変数を共有しないよう選ぶ。選択行の制約を足すと、全変数の和は選択行数以上になる。目的定数も厳密整数で安全な表現範囲なら、目的定数と行数の和を厳密整数の下界として報告できる。上限や整数性はこの不等式には不要。

初期集合は元行の逆順で貪欲に構成する。未選択行を妨げる選択行が1本だけなら候補としてまとめ、互いに非交差な候補2行でその1行を交換する。交換後の所有変数を再確認し、不変条件が崩れた場合は証明を返さない。追加で埋めた行に対して古くなった候補は、現在の所有者と突き合わせて除外する。

探索・枝刈り・最適/不能判定には使わない。root前に全体予算の5%、最大0.25秒で計算し、時間終了時も成立する集合だけを報告する。変数/行各10万・係数1000万まで。既定無効、MIP_ROW_PACKING_REPORT=1で診断する。均一乗数版とは別機能/別ブランチで評価する。

証明は選択行番号の昇順一意な配列と正規化整数下界。独立検査器が元MPSをFractionで読み、元目的係数/下限、行係数/下側定数、非交差性、定数+行数の完全一致を検査する。下界が強くても最適性や実行不能を宣言しない。

先行する独立例ではcygnetの逆順169行を1対2交換1回で170行へ増やし、元MPSの厳密下界170を確認した。300小例の全列挙照合が全成功、合計91交換。36順序の行別双対貪欲では169を超えず、単なる順序数追加より交換を検査する根拠とした。holdoutは利用しない。
