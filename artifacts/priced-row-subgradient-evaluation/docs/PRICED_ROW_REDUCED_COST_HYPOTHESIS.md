# 被覆乗数からの目的条件付き固定（診断のみ）

検証済みの非負乗数yに対し、単位箱のreduced cost r=c−A^T y、Lagrangian下界Lを使う。x_jを符号で選ぶ最小化端点と反対に固定した領域の下界はL+|r_j|となる。これが厳密に検証された整数点の元目的値Uを上回る場合、その反対側は改善解を含まない。これは目的値条件付きの固定であり、元問題の変数が無条件に固定されるという主張ではない。

独立Python Fraction診断は元MPSを読み、全変数が厳密0/1の整数点で全原行を厳密に満たすことを確認した。元費用/offsetとIEEE乗数を正確な有理数で計算し、L+|r_j|>Uと現在点が残る側にあることを検査。N3div36は22120変数中3593候補、SP97 14101/SP98 15085/fast0507 63009/eil33-2 4516変数は候補0。5件の元点はすべて厳密実行可能だった。元MPS/点/証明SHAと各変数の有理数不等式を保存した。

主ソルバーでは未実装で、枝刈りへ使っていない。将来Rustへ実装する場合は元点の厳密な実行可能性と目的上界、元入力の区間演算による反対側下界、独立した固定証明の検証が必要。許容差内の点を厳密実行可能と置き換えず、厳密guardを証明できない入力は固定しない。モデル名や既知値を条件にしない。まず小規模全列挙と元MPSのproof oracle、次に短期/60秒対照で判断する。
