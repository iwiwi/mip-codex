# 零費用singleton初期基底の採用評価

main PR107との併用を評価した。人工列が必要な行だけ、零費用・単一行・2冪係数の元列を実行可能な対角基底に使う。元モデル、枝刈り、最適性・不能判定、検証許容幅は変更しない。既定有効、MIP_LP_SINGLETON_CRASH=0で解除できる。

開発188問を各10秒、同じ凍結実行ファイルの設定だけ切り替えて比較した。主解2改善・0悪化・186同等、下界5改善・1悪化・170同等・12比較不能。有限下界は両側176問。終了状態は両側とも時間制限171・資源制限11・最適1・数値エラー5。376出力の証明と122個の元問題解は独立検査ですべて有効だった。これは開発評価であり、保留52問を含む最終240問の評価ではない。
