# 多様化した局所探索の適応的予算

PR39では旧探索へ時間を増やしても改善しなかったが、PR41の再構築で同じ0.25秒の主解が-187→-190へ変わった。次案は多様な再構築を長めに許しつつ、改善が長く止まれば終了する。

全体5%・最大2秒、最大128n/500000反復とし、16n（最低256）反復改善しなければ止める。旧は最大0.25秒・8n/50000反復を維持する。MIP_GRAPH_ADAPTIVE_LOCAL=1で試験、既定無効。予算・上限・最終改善反復・終了理由を保存する。最良点の全ペア厳密検査、元MPS検査、上界・枝刈り条件は変えない。

時間を使うことで証明が遅れる可能性を測る。15/60秒のsorrell3とBenchmark外sorrell7、固定開発問題、全列挙で比較し、改善がなければ採用しない。既知値や解、問題名を最適化へ渡さない。
