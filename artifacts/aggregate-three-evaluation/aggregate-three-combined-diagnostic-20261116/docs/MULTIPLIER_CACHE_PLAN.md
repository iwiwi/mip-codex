# 基底に属する双対乗数キャッシュ

プロファイルでBasis::backwardとwarm_implが多くを占める。双対乗数B^-T c_Bは基底と基本変数の目的係数だけに依存し、RHSや上下限には依存しない。同じ基底・同じc_Bなら再計算した数値そのものを再利用する案を検証する。

Basis内に入力c_Bと結果を不変Arcで保存し、入力はto_bitsで比較する。Basis::updateは必ずキャッシュを破棄し、再分解で作る新Basisも空から始める。初期対角因子の直接設定も破棄する。WarmStartの基底cloneは不変のキャッシュを共有し、子の更新では子だけを破棄する。一般のBTRAN（dual pivotのunit vectorなど）はキャッシュを更新しない。目的関数が変わっても基本変数部分がbit一致するなら乗数は同じで、非基本変数のreduced costは従来どおり再計算する。

certificateの主残差・全reduced cost・元問題の検査は省かない。ピボット、数値閾値、不能判定は変更しない。cache hits/missesをLP統計とMIP合計へ記録する。行列・基底が変わった状態の乗数を再利用しないことが最優先の条件である。

不変snapshotのPR44を旧版として、同じgen-ip002の37993節点を同じCPU7/1thread/16GiBで3反復する。全非時間フィールド（新規cache統計以外）を比較し、2700合成MILP、300根LP、32数値回帰、固定18問と元MPS検査で確認する。cache-hitだけで性能向上と数えない。
