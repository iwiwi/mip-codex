# 費用を考慮した主解修復

既存Repairの実行可能性改善gainを、gain/(1+weight*max(cost,0)/scale)で順位付けする独立診断。costは最小化向きの目的変化、scaleは正の目的係数の中央値。重み0は元の順位を保つ。候補の受理は元問題のguardのままであり、失敗は大域不能・下界に使わない。
