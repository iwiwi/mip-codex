# 被覆乗数の射影劣勾配診断

未統合の独立例examples/cover_dual_subgradient.rs。元単位箱・単位費用の問題で、自作の非交差行乗数を開始点にし、元の自作整数解を目標上界/零reduced costのtie選択に使った。任意の非負乗数の値は既存Certifierで元入力から外向きに計算し、候補選択の近似値は証明に使わない。

cygnetの自作点218を使い、最初の2秒178反復では下界170から改善なし。減衰を加えたv2は更新係数0.1/0.5/1/2の各2秒、175–176反復でもすべて同じ170（外向き169.99999999999758）。構築/最終証明を含む実測2.08–2.09秒を保存。採用しない。

このクラスのLP緩和そのものが170に近いかは未確認。比較専用HiGHS連続LPを60秒で診断する。既存ソルバーへ自作の最適化を委譲するものではなく、その点/乗数を主ソルバーの探索に使わない。結果を見て継続/棄却を記録する。holdoutは利用しない。
