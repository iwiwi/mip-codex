# 初回根LPと切断準備予算の分離

伝播なしの改訂単体法で切断が適用可能なら、初回根LPは全体期限まで解く。初回終了後の候補生成・追加行再最適化は従来の5%/最大0.25秒に制限する。切断を追加していなければ、取得済みの標準化Problem、元変数/行の対応表、LP回答を主探索へ所有権ごと渡す。切断追加後の古い回答は使わず、行拡張可能な基底のみ渡す。伝播有効時は旧準備方式を維持する。

初回の非最適回答も通常の主探索へ渡し、不能や数値エラー等の二重計算を避ける。後続の切断準備LPの時間切れは全体期限と別なので保存せず、主探索で残り全体時間を使う。元問題の点、目的、不能、下界の検査は変更していない。期限終了直前の取得済み根回答は通常の検証を一度だけ通すが、新LPは解かない。

cut_secondsは準備の合計時間で、初回根LPの時間を含む。新しいcut_initial_lp_secondsでその部分を区別し、root_lp_reusedで保存回答の利用を記録する。再利用時にLP回数・ピボット等を二重加算しない。

Rust197テスト成功。新たに、追加切断なしの根をwarm無効でも1回しか解かない例、1roundでは切断前回答を棄却し2roundでは最後の結果を使う例、伝播/切断無効、時間/節点0、pivot0、元小数行の不能証明を検査した。最初のテスト入力は完全冗長行で切断適用外だったため、適用可能だが根最適点で切断不要の行に修正し、失敗ログも保存した。

最終コードで2700合成（ordinary500/larger300/binary500/mixed500/rounding500/projected400）、根LP400（ordinary200/scaled100/units100 revised）、32数値例、cover checker8/objective grid checker6/preflight8/validator3が成功した。固定18問の10秒status/primal/dualは直前のPR62版と全一致。13保存MIP点がGMP絶対/公式検査成功、18記録160切断が独立検証成功した。
