# 同時Farkas乗数摂動による区間証明の補完

元問題への不能証明が単独乗数の相対±2^-32調整でも得られない場合に、絶対値上位8乗数の同時±調整を全組合せ、全体符号も両方試す。最大512候補。元係数と境界の区間演算による厳密な下界が正の場合だけ受理する。候補は証明の代わりにならず、失敗時は元の保留下界を維持する。`MIP_JOINT_INFEASIBILITY=0/1`で比較でき、採用版は既定有効。各追加候補前に探索期限を確認する。

## 検証と限界

固定開発18問の主解/下界/statusは直前版と全て一致。2700合成MILP（1000小規模/200大規模/500混合切断/1000 binary）、根LP200通常+100scaled、数値32例成功。最初のscaled起動は環境変数名を間違え、通常100例になったのでログを保持して正しく再実行した。

追加Rustテストは80個の厳密実行可能な小数モデル×8種類の元乗数×64候補で不能証明を返さないこと、寸法不整合/NaN拒否、正しい矛盾の証明、期限経過で0試行を確認。最初の正例テストはMPSの一行に3組を入れて入力parseで失敗し、2組に分割して修正。期限追加の編集スクリプトは置換対象探索で一度失敗し、ソースを書かずに終了した。

保存された元問題の解31点のGMP/公式検査、41記録/134切除平面証明の再検査が成功。別に固定節点2点のGMP/公式検査成功。同じ問題の反復を独立した問題とは数えない。枝刈り木全体の独立再生はしていない。

最初の失敗dumpはnode-proof-boxブランチ9b358c01の不採用試作に保存。そこでは節点有限箱推論は効かなかったが、同時調整7候補目に正の下界1.5563154424754655を得た。今回の失敗dump群も保持し、次は残る未証明領域とLP冷再解法の比較を調べる。

最終の期限確認を含む既定版でも同CPU7/100000節点で再確認し、無効8.08077/有効8.07866秒、同じLP回数/ピボット/主解/下界/返却点、未証明13→5となった。追加2点もGMP/公式検査成功、保存された検査済み点は合計35（31再検査+固定2+最終固定2）。168 Rustテスト成功、保存dump診断1件は通常実行でignore。全240問snapshotはcreate-onlyで起動しない。ソースfda51134、詳細receiptはexperiments/joint-proof-snapshot-20261115.json。
