# 二値clique切断の再評価

過去PR31も元行の全pair排他性による切断を試したが、固定18問と追加6問ではclique追加0で未採用だった。今回は根LP予算分離後の保存77根点を調べ、元行からのcliqueがLP下界を改善する候補を先に確認した。診断の詳細はCLIQUE_CUT_DIAGNOSTIC.md。

Rust版は符号付きliteral、整数係数の元行、非二値項の元の厳密整数境界を使う。生成とは別の既存cover証明検査で全対を確認し、元行/側/2変数を保存する。Python検査は元MPSのFractionから全pairの厳密最小活動量とcliqueの全対・符号・右辺を再計算する。32literal/512候補/64seed/仕事2M、分離20ms（構築10ms、成長15msまで、残り証明検査）で制限する。proofを緩めたりnativeの点/双対乗数を戻したりしない。

Rust202成功、200符号付き8変数グラフを全256点列挙、証拠改変・正負literal・連続投影・主探索結合を検証。2700合成、400根LP、32数値例、clique checker3/cover8/objective grid6/preflight8/validator3も成功。既存の機能分離テストでは新切断を明示的に無効にした。初回divingテストは新切断が根で問題を解いたための前提不一致で、失敗ログも保存。

保存77点でRust分離器が追加したのはeil33-2の5本とnw04の1本。全6本が独立Fraction検査成功。eilA101-2は10ms構築枠内では追加0で、Python診断の12本と同じ効果を主張しない。固定18問の10秒status/主解/下界は直前PR63版と全一致、追加clique0。13保存MIP点はGMP絶対/公式成功、18記録160既存切断は独立証明検査成功。
