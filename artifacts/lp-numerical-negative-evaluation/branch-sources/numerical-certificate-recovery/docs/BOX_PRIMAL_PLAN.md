# LP前の箱候補と実行可能な座標降下

LPが時間/メモリ制限で終わる場合にも主解を残せるよう、LP前に0・下界・上界・費用に有利な端点を箱へ射影して検査する。実行可能な候補からは費用改善/列の次数の順に端点変更を試し、影響する行を近似活動量で判定する。最終点は既存の元問題/桁落ちguardで再検査し、不合格なら最後に検査できた点を保持する。

実験は既定無効、MIP_BOX_PRIMAL=1で行った。gmu-35-50とsorrell3で主解改善を再現し、最終検査後に既定有効として採用する。MIP_BOX_PRIMAL=0で無効化できる。根の5%・最大0.25秒の枠内で実行し、incidenceは既存のLP後修復へ再利用する。probe/RINS内部では再実行しない。下界・実行不能の根拠には使わない。LPが始まらなくてもstatusはresource_limit/node_limit等のままとし、optimalと混同しない。

RustのLP不能/正負目的/目的定数/実行不能/0秒/桁落ちの検査、LP0節点の200小問題を全列挙・GMP照合、既存2700合成・32数値回帰、固定開発18問と大規模開発問の比較で採否を決める。箱候補の最初の発見時刻と仕事量・変更数を保存する。

許容誤差内の主解と根の実行不能が衝突する場合は、枝を残してnumerical_errorを返す。最適性や実行不能を宣言しない。矛盾する境界と第1段階LPの両方で回帰検査する。
