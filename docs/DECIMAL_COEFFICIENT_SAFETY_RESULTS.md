# 小数係数の元問題下界検証

## 問題と採用判断

main121 cb0ba03a36c3f07e は min −x、0≤x≤2、0.99999999999999999999 x≤1 に下界−1を返す。元の最適値は −100000000000000000000/99999999999999999999 であり、下界が厳密に最適値を上回る。目的値の相対許容とは別の正しさの問題である。

字句の係数がbinary64で整数に見えても厳密な整数係数とは扱わず、元係数を囲む区間でLP下界を再検証する。明示されない変数境界は元制約から保守的に導く。下界を証明できなければ証明済み親下界のみで分枝・主解探索を続け、未証明の葉が残ると最適性を撤回する。密LPも双対乗数を内部へ返して同じ検査を受ける。数値許容は緩めず、既存最適化ライブラリへの委譲もない。

最終候補fb986443b5 / 8b579cacb175412dを正しさの修正として採用する。性能上の損失は下表のとおり残る。性能優位・新記録は主張しない。

## 独立した正しさの検証

- 最終候補: Rust 334成功、4ignored。丸めで整数に見える小数、両目的方向、自由変数、未証明葉で主解保持と最適性撤回を検査。
- 解析LP: 疎・密各216例。修正前の非保守的下界94/108例→最終候補0/0例。JSONの10進表現とbinary64の正確値を、解析解のFractionと許容なしで比較。最終候補は全例optimal。両版・両エンジン合計864点GMP有効。全4実験版の3456出力・3240最適宣言について解析最適値との相対1e−8目的値検査も成功。
- 混合整数200例: 整数変数を全列挙し連続変数を有理数で解く。最終候補は不正下界0、186optimal/14numerical_error、全200点GMP有効。14件は既存の厳密な元点検査で最適性を撤回した例。
- 一般800/二値400出力: 各実験版で全列挙一致、実際の親下界証明710+318件、改ざん拒否5680+2544件、GMP各1200点有効。親下界の検査に数値許容を入れていない。
- 短い補助実験の6点、最終候補の追加pilot2点もGMP有効。pilot2点は公式検査も有効。

GMPは元MPSに対する行・変数境界・整数性を絶対1e−6、目的値を相対1e−8で検査する。主点の許容と最適性・下界の証明を混同しない。
