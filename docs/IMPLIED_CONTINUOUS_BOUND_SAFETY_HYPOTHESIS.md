# 連続変数を介した整数境界の安全性

2026-11-17。main 4b9cf54 / FPcdfc159e435d9194 で、整数 x と連続 y を等式で結び、y の上限を数学的境界より極小量だけ小さくすると、真の最適値0に対して -1 の optimal を4件で再現した。原記録は artifacts/implied-lattice-boundary-pilot/。係数は (x-y,3x-4y,x-3y,x-2y)、上限制約はそれぞれ y<1,y<3/4,y<1/3,0.1y<0.05 の有限十進入力。整数 x の0..2を Fraction で全列挙した。

従来の外側区間による確定違反チェックは、区間が境界に重なると断定を避ける。その振る舞いを最適性の承認と組み合わせた点が不十分だった。整数宣言だけで行丸めを行うPR117でも連続変数の暗黙の格子には対応できない。

当面の修正では、元入力の係数・境界に二進表現の不確かさがある行・変数に対して、外側区間全体で実行可能と確認できない場合、optimal を numerical_error に変更し dual_bound/gap を撤回する。候補点は既存の独立絶対許容幅検査の対象として保持する。これは違反証明ではなく保証不能による保守的な撤回であり、実際に正しい境界上の解も撤回しうる。係数・境界が正確な入力には新たな撤回を適用しない。3y=1 の近似出力の扱いは維持する。

小規模回帰、全Rustテスト、既存の境界コーナー、開発188件の比較と独立検査を行う。性能研究2件はこの安全性の評価後まで採用しない。長期的には元十進数を保持した有理数の実行可能証拠で保守的な撤回を減らす。

## 追加反例と範囲変更

元入力が厳密な二進数でも、(1+2^-52)x-2y=0, y<=0.5, x整数0..2 で旧mainは -1 を optimal と返した（真値0）。artifacts/implied-lattice-exact-binary-pilot/ に保存。従って非二進十進入力だけへの適用では不十分だった。

現在の候補は、最適点の整数変数が厳密な整数であること、変数境界と全行を二進値の点自体で満たすことを外側区間で確認する。元係数の不確かさは残し、点のシリアライズ誤差は二進値の点の存在証明には混ぜない。小さい厳密整数和の場合は既存の元十進ceil/floorも利用する。3y=1 は二進点を厳密に構成できないため、目的値の精度を維持して最適性のみ撤回する方針に変更した。非二進十進固定値0.3も同様。元の数学的モデルに真に実行可能な有理点を復元する実装が次の改善となる。

この処理はprimalの十分条件であり、LP/MIPの完全な最適性証明器ではない。探索中の下界・枝刈りの数値的正しさは独立の既存証明検査と全列挙で別途検証する。

全テストで、非二進固定値0.3、射影cutの下限0.1、MIRのゼロ目的実行可能点、3行cutの連続点が追加の撤回対象になった。これらの目的値、点の絶対許容幅検査、cut証明、node_limit時の親下界の既存検証は維持し、最適性撤回・dual/gapなしの検証を追加する。許容幅で通る候補点と厳密な最適性を区別するための期待値変更であり、誤最適を受理するような許容幅の拡大はしない。
