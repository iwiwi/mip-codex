# 局所探索の予算増加は不採用

既定0.25秒/8nに対し、15秒実行で最大0.75秒/256n、60秒実行で最大2秒/256nを同じバイナリで比較した。sorrell3/7の15秒・60秒、計8実行はすべて元MPSのGMP絶対/公式検査と根構造検査で有効。162Rust、1200CLI全列挙/3600偽証明拒否、32数値回帰も成功した。

主解/下界は全比較で不変。15秒はsorrell3 -16/-24、sorrell7 -187/-379。60秒はsorrell3 optimal-16/-16、sorrell7 -187/-379。sorrell7は約15147→121716局所反復でも改善せず。sorrell3は同じ6777969節点で証明時間20.668811725→22.720895098秒となった。単に予算を増やしても効果がなく、探索時間を消費するため、設定追加と予算変更をmainへ採用しない。

初回ビルドはmainのStringエラー型にparseのエラー型を変換しておらず失敗した。修正後の全検査は成功。失敗ログも保存する。

追加の根彩色比較ではsorrell3の60秒上限実行が強化前18.336413471秒/6042153節点、強化後20.6328997秒/6777969節点となった（両方optimal-16）。これはPR38のsorrell7下界改善と併せて報告する。次は元の根探索順を維持し、各prefixに対して複数の正しい彩色の色数の最小値を上界とする。根色数が少ない候補へ探索順を変える必要はない。独立検査器も実際の根順と全候補彩色からprefix上界を再計算する必要がある。
