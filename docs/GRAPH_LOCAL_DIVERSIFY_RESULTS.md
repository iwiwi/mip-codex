# 停滞時の再構築を多様化して主解を改善

改善が64反復止まった時に最良集合へ戻るだけでは似た探索を繰り返すため、その集合から一部を外し、固定seedで並べ替えた順に競合しない頂点を追加する。最良集合を保存する前に全ペアを厳密検査する。時間枠は既存と同じ全体5%・最大0.25秒、反復上限も変更しない。上界や枝刈りの数学には変更がない。
