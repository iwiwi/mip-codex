# Cayley構造と整数スペクトル上界（私的プロファイル）

理論参考: Haemers (2021), Hoffman's ratio bound, https://arxiv.org/html/2102.05529v2 。weighted regular adjacencyにも同じ比率上界が成立するという数学を参照し、外部コードは使用しない。

nが2冪の既存uniform binary packingグラフに対し、元入力順・重み順の二進語の一般的な並べ方を試す。全辺/非辺で conflict(u,v)=mask[label(u) XOR label(v)] を厳密に照合する。ラベル候補だけで構造を仮定しない。さらにmaskがHamming重みだけに依存する場合、距離shell毎の重みを自作Rust revised LPで探索する。変数はshell数、制約は異なるWalsh固有値行。外部LPへの委譲はしない。

LP点の可行性や最適性を上界証明に使わない。得た重みを整数へ量子化し、非辺と対角の重みを0に固定する。整数FWHTで全固有値を再計算し、D=行和・L=最小固有値に対して floor(n*(-L)/(D-L)) を厳密整数演算で証明する。独立集合の指示ベクトルfはf^TAf=0であり、定数成分と直交成分の分解から 0>= (D-L)|S|²/n+L|S| となる。signed重みの場合もこの導出は同じ。L<0,D>Lを満たさなければ棄却する。

私的exampleのみで本体変更なし。元MPSからの独立整数検査、生成小グラフ全列挙、改変証明拒否を先に行う。問題名・既知値・固有の距離shellは最適化判断に埋め込まない。cod105で一般的なgraded-lex順を全辺検証して構造を検出できたが、他の開発例での不検出も保存する。記録更新や全体優位は未達。

追加仮説: 非辺の重みを0に限定せず、非正整数まで許す。この場合も独立集合のf^TAf<=0なので同じ比率上界を導ける。LPでは全Hamming shellを変数化し、競合shellは[-1,1]、非競合shellは[-1,0]とする。LP近似点の可行性に依存せず、量子化後の非辺符号と整数固有値を独立検査する。

本体候補: 根彩色の後・主解局所探索の前に実行し、初期解と同じ整数上界を証明できれば局所探索や枝探索を省く。総制限の2%・最大0.25秒、補助メモリの事前検査、全辺の構造照合と証明の非辺符号検査を行う。元のgraph認識条件と元問題の解検証は維持する。元行被覆MIP_GRAPH_INPUT_COVERとスペクトルMIP_GRAPH_SPECTRAL_BOUNDはいずれも初期既定0、独立に切替可能。比較前後は同じ凍結実行ファイルで両0/両1を比較する。LPは補助重み生成にのみ使い、実行した回数・pivot/refactorを本体Resultにも報告する。LP近似解の状態を元問題の境界証明として転用しない。

私的V2ではcod105の整数固有値D=88429880,L=-1048580から上界12を計算した。元MPSを読む別Pythonの直接Walsh和検査に成功、非辺を正にした上で固有値メタデータまで更新する偽証明も拒否した。小規模200モデル×2重み方針=400出力の全列挙・独立証明が成功、2400改変を拒否。これを本体で再現してから採用判断する。新記録や全体優位は主張しない。
