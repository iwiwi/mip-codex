# 単調な連続変数を持つ制約からの主解構成

main123を基準にした隔離exampleのみ。productionは変更しない。ある連続変数に上限がなく、その変数を増やすと全ての出現制約が緩むなら、その変数を含まない制約だけから実行可能点を作り、最後にその変数を持ち上げられる可能性がある。逆方向（下限なしで減少）も対称。問題名や答えは使わない。元係数が正確である単一出現のみをlifting列として扱い、重複項・上下両制約・方向矛盾は除外する。候補を出すだけで、部分問題の下界・最適性・不能は元問題へ移さない。

最初の診断は出現行数が最大の列を1本選び、その列を含む行を全て除き、元境界内の値へ一時固定。残りの目的を0にして自作Rust solveで実行可能点を探す。点が得られた場合のみ、元行RHS区間と係数・出力点の誤差を外側から囲み、必要な持ち上げ量を計算する。元全行のcandidate_checkと独立GMP点検査を必須とする。現段階は主解構成の可能性だけを見る診断であり、main同時限比較ではない。

rd-rplusc-21の入力読込のみの構造調査では、自由連続変数が118801片側行に現れ、残り7098行がある。目的列は2本であり単目的列という初期仮説は誤り。部分問題の主解を作れるかは未検証。初回exampleビルドはdot_boundsの配列をtupleとして添字指定した誤りを検出し修正、ログ保持。

## 最初の診断結果

10秒・60秒とも主解なし。全118801行の分離はできたが、残る7098行の根LPが60秒で1,393,779 pivot、27,875 refactor、1 node / 1 LP solveの時間制限となった。部分問題のdual0は親へ転送していない。liftingそのものの点検証へは到達しておらず、まだ採用できない。次はLPの退化・反復挙動を診断し、必要なら一般的なcycling対策を検討する。生成モデルでlifting点構成を検証する作業も未実施。

10秒traceでは最初のdual-form根LPが619行/8405列、目的0のまま約23万pivot全て退化。4096 pivotごとの58標本には基底ハッシュの反復は見られず、循環と断定しない。その後7098行のprimalへfallbackするが残時間不足。次は目的0の実行可能性問題でdual rootを無効化する診断を行う。これは既存Limitsの変更であり、LP数学・許容差は変えない。

退化対策の参考としてRobert G. Bland (1977), “New Finite Pivoting Rules for the Simplex Method”, Mathematics of Operations Research 2(2),103–107, DOI10.1287/moor.2.2.103を確認（原論文 https://people.ohio.edu/melkonia/math4620/bland.pdf 、出版社 https://pubsonline.informs.org/doi/abs/10.1287/moor.2.2.103 ）。最小番号のenteringと最小比同率内の最小番号leavingを組み合わせる方法。現コードは退化後enteringを最小番号に寄せる一方、ratioは安定性を優先するHarris型であり、同じ規則ではない。実数算術の有限性を浮動小数点・有界変数実装へ無条件に主張しない。論文のコードを複製せず、まだpivot規則の変更もしていない。

primal根LPに切り替えた10秒診断は115 nodes /193 LP solves /18739 pivotsまで進んだが主解なし。60秒も主解なし（全統計を保存）。したがって行分離だけを採用する根拠はない。lifting点構成の生成200モデルは両方向・MIN/MAX・元の非二進十進係数と非零固定列を含め、全200点GMP合格かつ元MPSをFractionで読んだ許容差なしの全行・境界・整数性検査にも合格した。局所主解から親の下界・不能・最適性を返さない。今後の課題は残余MIPの主解探索であり、既存の目的ゼロ化とprimal形式だけでは不十分。

次の独立診断では、残余問題の目的を0のままにする方式と、分離した列を除く元目的を保つ方式、有限境界の整数列へ決定的な小整数係数を付ける方式を比較する。実行可能点だけが目的であり、任意の補助目的の下界は親へ返さない。残余問題の単調有限境界列を調べると該当は5列で、残る元目的列は該当せず。まだ固定処理は追加しない。元入力名・答えでの分岐は追加しない。
