# 改善系列だけ目的cut探索を継続する

親実装の16 seed上限は、SP97/SP98の60秒枠で共通2秒予算の手前に停止している。一方、独立2秒診断はさらに良い整数点を得た。16 seed以内に少なくとも1回改善した場合だけ最大64 seedへ進め、改善0の系列は従来どおり16 seedで打ち切る仮説を検証する。モデル名、native解、既知最適値は条件や入力にしない。

共通wall期限5%/最大2秒、合計100M work、元点保持、元モデル候補検査、目的値誤差guard、4e−8改善marginを変更しない。継続が失敗した場合も既存最良点を保持する。LP予算を払い戻さず、証明・枝刈り・不能/最適終了に使わない。既存公開API improve_pricedは16 seed動作を保持し、CLI MIP_ROOT_PRICED_CONTINUEは実験既定falseとする。

10秒枠はSP97/SP98が0.5秒に達して16 seed未満、eil33-2は16 seedまで改善0だった。継続条件によりこれらの短期動作は同じと予想するが、測定で確認する。60秒対照で改善を確認し、元MPSの独立絶対/公式検査、継続条件の小規模試験を通してから採用する。
