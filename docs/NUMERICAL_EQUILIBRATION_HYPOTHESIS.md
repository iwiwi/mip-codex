# 数値停止後だけ強い行列平衡化で再試行

既存の列/行スケールは最大係数が[1e-4,1e4]を外れる場合だけ2冪で正規化する。通常法が数値停止したLPについてのみ、すべての非零列最大値と、その後の行最大値を2冪で正規化してcold再試行する。従来成功パスは維持し、前試行の仕事を総pivot/flip/deadlineへ残す。再試行は1回だけで、元Problemでの点/dual/矛盾/ray検査も既存のまま。まずFP8bの進捗復元版とnidda/app1の10秒MIPおよび未解決LPを比較する。新方式は未採用で、進行中の188/3行集約の凍結測定には混ぜない。

10秒MIPの5問題対照では主解・dualの改善なし。niddaは70→513nodeへ進むが約1.56→5.40秒で数値停止し、14054.945596895/−1216923.270104406は同じ。最後のscaled infeasible候補は元単位の矛盾検査に通らずNumericalErrorとして停止した（枝刈りへ昇格しない）。app1は両方点なし時間制限、glass4は3466706233.3333354/800002400・数値停止で同じ、leo1は点なし389771802.1527368・数値停止→時間制限、crnaは点なし0・数値停止のまま。ノード数や時間制限への変化だけを性能改善と数えず、未採用とする。nidda前後の2点はGMP絶対/公式検査とも有効。glass4前後を含む追加点も独立検査する。
