# 次の構造仮説: conflict graphの連結成分

純binary packingを表すconflict graphが分離していれば、各成分の独立集合は互いに両立し、原問題の最大cardinalityは成分ごとの最大値の和になる。現mainの彩色/探索は全体を一括しており、小成分に分けた方が容易になる可能性がある。既存Rust探索の再利用を私的に調査し、元MPSで全点を検査する。成分の境界や最適性を本体へ採用する場合は、元MPSから独立に成分の完全分割・成分間辺なし・各成分証明・加算を厳密検査する実装が必須。未実装の段階で最適性を宣言しない。
