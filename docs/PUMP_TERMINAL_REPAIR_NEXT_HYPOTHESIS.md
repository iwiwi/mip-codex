# 次候補: pump終端点の短い元行修復

現pump打切り回収の初期188問でlimited_pointを得た17問中、単純丸めが元行検査を通ったのは1問、16問は拒否された。元点は補助L1距離LPの進行点であり、整数解に近くても制約可行ではない。

次候補では既存Repair::search_adaptive_incrementalを、単純丸め拒否後だけ元変数へ写像した点に適用する。外部optimizerは使わない。全体期限内の最大100msかつ残時間の1%以内、最大work固定、元bounds/同じ受理checkerを使い、補助LPのdual/basisは使わない。連続座標も元boundsの範囲で修復可能とする。修復失敗は既存探索へ復帰し、数学的宣言は変えない。

現在は未実装。pump既定ON候補の全検査/188比較を閉じてから別branchで実装する。最初に旧188でlimited_point>0だった全17問を事前選択し、同一凍結binary OFF/ONで10秒/16GiB/1thread比較、全点元GMP/公式・全proof検査を実施。対象選択は品質や成功を見て変更しない。正しい受理以外に全体時間の減少による主解/dual損失も保持する。利益が無ければ採用しない。
