# pump射影予算の負の実験

混合binary pumpの制限解除だけではkrkaの最初の射影LPが1秒以内に終わらなかった。同じ制限時間60秒の10%を保ちながら、pump上限1秒を5秒へ延ばした。最初の射影は約1.67秒で制限に達し、候補なしだった。ソース上の各LP4096ピボット/反転上限も制約になり得るため、次にそれだけをmax(4096, 2×二値変数数)へ広げた。

二つ目の版も5.004秒で最初の射影の制限に達し、整数解なし・双対境界0だった。比較側も整数解なし・境界0であり、主解改善はなかった。二つの60秒対照比較4出力は、元MPSの独立Fractionカット/補助証明検査ですべて有効（保存整数解0件）。

時間上限だけの延長も、規模に応じた反復上限追加も、この範囲では効果がなく追加時間を使うため棄却する。mainへ採用しない。最初の混合pump制限解除の記録はMIXED_BINARY_PUMP_RESULTS.mdにある。次の独立した仮説は主解probeの根基底再利用であり、この予算変更を含めない。
