# 自作乗数のbox最小点による主解修復

検証済み被覆乗数yからc−A^T yを計算し、符号による単位箱の最小点をRepairの初期点に使う。これは候補生成だけで、乗数の近似reduced costを枝刈りへ使わない。ゼロ側初期点を先に16 seed、残予算で乗数由来初期点を16 seed試す。選択側.95/非選択側.001の丸め入力、重み1の既存費用付きRepair、共通5%/最大0.1秒/合計100M workを使い、改善がなければ元点を保持する。

元Modelのcandidate_checkとobjective_reliable、4e−8相対改善marginを候補ごとに維持。非負費用のpure-binary厳密単位箱/元点が検査済み/新しい乗数証明がある場合だけ試す。初期ベクトル構築も共通期限内で行い、LP予算を払い戻さない。CLI MIP_DUAL_GUIDED_PRIMALは実験既定false。最初の主解は既に存在するためfirst-primal時刻は既存値を維持する。

独立helperはソース/ELF/SHAを実行前固定。5モデルの各モード個別0.5秒ではfast0507がzero230/dual234（元276）、eil33-2がzero1116.990809/dual1092.89421、他3件同値。個別予算の足し合わせを性能値にしない。共通0.5秒portfolioはfast230/eil1092.89421、共通0.1秒でも両改善を再現し他3件同値。計30点すべて元MPSのGMP絶対・公式検査有効。実測は時間確認単位の超過を含め0.106〜0.113秒など生値を保存する。

main PR91/FPeb58f7ae33131dafを基点に別branch dual-guided-primalへ統合案を追加。既存243 Rust後、200小例全列挙/元制約と目的値保持/node_limit・LP0回・主解保持の追加検査を行う。ソースを固定して選択10秒、開発188対、60秒、native比較と元MPS独立監査を完了するまで採用しない。全体優位・新記録は未達。
