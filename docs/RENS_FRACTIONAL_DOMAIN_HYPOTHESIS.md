# LPでfractionalな一般整数だけを元範囲へ戻す近傍

strict丸めと固定緩和が局所不能で終わる場合、床/天井に制限した一般整数自体が原因かを検査する追加案。MIP_RENS=1・MIP_RENS_RELEASE=1・MIP_RENS_EXPAND=1で、残時間がある時に3番目の近傍を一度だけ試す。初回の近傍でintegerだった変数は固定を維持し、2番目に緩めた変数集合も同じ初回ヒントから再構成する。LP-fractionalな一般整数のうち、床/天井より元の範囲が広い変数だけを元Modelの境界へ戻す。0/1など変わらない変数は除き、expanded0なら再試行しない。

固定を緩める候補がなく2番目を作れない場合も、範囲拡大だけが可能なら3番目へ進める。全部の走査・近傍複製・3探索は同じ全体10%・最大1秒を共有する。局所不能/最適/下界は親へ使わず、元Modelの行/境界/整数性/有限目的と既存下界との整合を通る点だけを採用する。元の範囲より外には広げず、親Modelとwarm/pseudocostは不変。MIP_RENS_EXPANDは既定無効。

5単体検査成功。integer x in[0,3], y in[0,2], 2x-3y=0, x>=0.5、費用x+yに孤立した整数変数を加えた例では、LP x=0.5/y=1/3の丸め近傍に整数解がない。固定を緩める隣接変数もないが、元範囲を戻すとx=3/y=2の目的5を得る。実呼出し2回（中間は省略）、expanded2、released0、元点有効と親境界不変を確認した。全体・実行確認付き生成検査後に実問題で比較する。
