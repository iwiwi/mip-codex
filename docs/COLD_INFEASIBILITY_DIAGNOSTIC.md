# 未証明不能節点の冷LP診断

2026-11-15。joint-proof-evaluationに保存した20失敗節点を、dumpの元Modelと節点boxからstandard_sparseで再構築。自作Rust revised::minimizeをwarmなし、100000ピボット/5秒で実行した。全20例が不能となったが、通常区間証明は全て未成立、同時調整を加えても1例だけ成立した。冷再解の常用はこの証拠では割に合わないため未統合。診断コードとログをこのブランチに保持。

次の仮説：個別行では有限上限を導けないが、非負の行結合により全変数に正の係数を持つ有効行を作れる。その行から有限箱を区間演算で推論すれば、ゼロ付近の残差に有限の寄与を付けて証明可能になる。保存genモデルは全上限制約の和で係数が負になる列は1個だけで、その列が正の行を追加すれば全41係数を正にできる例が複数ある。元区間演算で検証した行結合のみ利用し、探索boxは変更しない。
