# 静的列ノルム価格付けの診断（採否未定）

Dantzig順位を、L2はreduced/sqrt(1+Σa²)、L1はreduced/(1+Σ|a|)へ変えた。適格列の判定、tolerance/noise floor、Blandへの切替、ratio、点/下界/不能検査は維持。有限正値の重みだけを使い、scoreがunderflowしても最初の適格列を失わない。

無制限L2（source112b741d8）はgermanrr根LP20.3507秒/7923pivot→12.9603秒/7185pivot、同じLP値を元MPSのFractionで検査成功。一方neos-860300は旧15.2168秒/22190pivotで完成した根が、60秒/96050pivotでも未完成。mcschedは旧4.4639秒の根が新1.8321秒/2494pivotでnumerical_error。固定18問ではbinkar7065.959979→7200.739991、mad0.3766→0.5324へ悪化。gmu-35-40、n5-3、beasleyC3は主解改善。timtabは主解なし/下界82576から主解1220083/下界130150へ改善したが、全体で採用しない。

無制限L1（source6dd07d54a）はgermanrr19.5188秒→10.6173秒、LP値同じ。neosは旧15.0235秒に対し新30秒/49050pivotで未完成、mcschedは旧4.4971秒に対し新2.2940秒/3105pivotでnumerical_error。固定比較でbinkar7065.959979→6868.120015、50v-10は3777.60→3629.10、bppcは65→59、madは0.3766→0.29、n5-3は10625→10125へ改善。一方markshareは1→2、beasleyは950→955へ悪化。無制限L1も採用しない。

各試作でRust202/合成500/根LP200（dense/revised/HiGHS）が成功。これは同じ固定seed/fixtureの反復で、別の独立1000/400例とは数えない。L2の保存MIP14点とL1の13点はGMP絶対/公式両検査成功。両版の18証明記録ずつも独立有理数検査成功。数値エラーは未検証の不能として剪定せずnumerical_errorとして保存した。

続いてL1補正を最大max(100,8*m)のprimal pivot/flipまでとし、その後は同じ基底からDantzig順位へ切り替える試作を行う。数値失敗したcoldは残りの同じdeadline/iteration予算でDantzigから一度だけ解き直す。再試行も原問題検査を通し、pricing_cutoffs/pricing_fallbacksを記録する。問題名による条件分岐は使わない。反復予算と多数bound flipのテストを加えたRust203が成功。これの根LP・固定18問比較を評価中。
