# 既知の境界点からのLP初期化

2026-11-17。main120を基準とする未実装の次仮説。開発用map10の保存済み主解0と-1は全164547変数が境界上（内部点0）。既知の実行可能点が非基本変数の上下限の組として表現できれば、初期人工変数を0にして冗長なPhase Iを省ける可能性がある。

候補点はLPの係数・境界・右辺を変更する根拠には使わない。既存warm startを優先し、cold初期化の追加候補として扱う。原モデルから標準形の変数への写像、scaling、固定変数、自由変数を明示し、表現不能な場合は従来初期化へ戻る。

標準形の非基本変数を下限0または有限上限へ置き、既存の単位slack/artificial列で基底を作る。全制約残差をexact::dot_boundsで確認する。等式の残差が厳密0、slackを基底にした不等式が厳密に実行可能、全変数が境界を満たすと確認できた場合だけ採用する。許容幅による受理やRHS/目的/列の改変は行わない。人工列の上限0固定とPhase II/KKT/期限・反復上限を維持する。

追加計算も全体期限に計上し、使えないhintや資源不足はcoldへfallbackする。元primal・親LP状態・元モデルを変更しない。部分モデルの状態を元問題の不能/下界に移さない。

まず実装箇所を調べ、小さなLPで上下限点・符号付きslack・warm/行追加・親不変・期限を検査する。独立Fraction/HiGHS比較とMILP全列挙、元MPSのGMP点検査・親claimの許容幅なし検査を通してから開発188件で判断する。問題名による選択や既知解の埋め込みは行わない。現時点で改善や新記録の主張はない。
