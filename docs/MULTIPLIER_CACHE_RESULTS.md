# 同じ基底の双対乗数を再利用

B^-T c_Bは右辺や上下限に依存しないため、基底と基本変数の目的係数が同じ時だけ保存した計算結果を再利用する。入力はbit単位で比較し、符号付きゼロも区別する。Basis内の不変Arcが結果を所有し、ピボットで必ず破棄、再分解は空から始める。子が更新しても兄弟や親のキャッシュは変えない。ヒット時の入力はiteratorで比較し、ベクトルの確保を省く。

一般のBTRAN unit vectorは対象にせず、全reduced cost、certificateの主残差/目的/dual検査は従来どおり行う。certificateで使う乗数も、同じ基底・同じc_Bから得られたbit一致の値だけを再利用する。基本変数の目的係数が同じなら非基本変数の目的係数が変わっても乗数は同じであり、reduced costは新しい目的から再計算する。
