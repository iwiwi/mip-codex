# 局所探索の予算比較

既定は従来の最大0.25秒・8n反復を維持する。MIP_GRAPH_LOCAL_SECONDSとMIP_GRAPH_LOCAL_PASSESで上限を指定し、全体の5%の時間枠と最大500000反復は常に守る。正の有限秒、正のusize回数だけ受け付ける。変更は初期主解だけで、根色数と証明の数学には影響させない。統計に実際の時間枠と反復上限を残す。

15秒では旧0.25秒/8n対新0.75秒/256n、60秒では旧0.25秒/8n対新2秒/256nを同じバイナリで比較する。sorrell3とBenchmark外sorrell7を使い、主解改善と証明探索の下界への影響を両方記録する。既知値や解をコード・初期値・停止条件に使わない。固定18問と元MPS/全列挙検査に合格し、実際の改善が確認されるまでは既定値を変えない。
