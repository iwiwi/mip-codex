# 混合五件の元モデル最適性保証の限界

pump候補のmixed_cuts固定seed200問で5件がnumerical_errorとなった。main129と候補OFF/ONに同じ点・状態を再現し、全てpump.calls=0。初回5点と再現15点は元GMP可行性検査を通過、15再現のproof検査も成功。Fraction独立頂点列挙の最適値はcase8 −79/35、40 −23/10、87 −9/2、122 1、169 17/5。参照値は測定後の診断専用で探索への入力ではない。

これは元モデルの厳密可行点・目的値と浮動小数LPの証明境界の整合を保証できないための最適宣言撤回である。primal_witness::finish は近傍有理点と報告目的値の整合を厳密有理数で確認し、Proof::respects_bound は宣言境界の向きを確認する。元十進モデル上の目的値を再計算するだけでは無効な向きのdualやそれ以前の枝刈りを正当化できない。

したがって目的値を丸める、guardを外す、許容差を広げる変更は行わない。将来の改善には元係数に対する有理dual証拠または独立した安全な境界と厳密主解再構成を組み合わせる必要がある。現時点の結果は195成功/5保守的未完了として保持する。開発188問の既存numerical_error4件はこのguard由来ではなく別のLP問題であり、混同しない。
