# 初回主解を探すRENS近傍

定義参照: Timo Berthold, RENS, https://edocs.tib.eu/files/e01fn09/573699097l.pdf およびSCIP公式説明 https://www.scipopt.org/scip/doc/html/heur__rens_8h.php 。定義の床/天井近傍だけを参考にした独立Rust実装で、既存コードの移植も外部ソルバーへの最適化委譲も行わない。

main PR109を親とする試作。MIP_RENS既定無効。最上位の根にfractional LP点があり、まだ主解がない時だけ試す。整数変数の80%以上・2変数以上をLP値の近くの整数へ固定でき、少なくとも1変数が未固定の場合だけ近傍を複製する。残る整数変数は床/天井と元の内側境界の共通部分に制限し、連続変数は変えない。変数が既に固定されている場合は固定率の分母から除く。元Modelは変更しない。

全体10%・最大1秒（近傍構築も含む）、4096node、LP上限4096pivotで自作Rust B&Bを使う。近傍内ではRENS/RINS/probe/他の主解ヒューリスティック/カット/目的丸め/伝播を無効にして再帰を止める。近傍の不能・最適・双対下界・warm基底・pseudocostを本問題へ戻さず、元問題の全行/境界/整数性/有限目的を満たし既存の証明下界と矛盾しない点だけを主解候補にする。localの終了状態と作業量は統計へ残す。

変数値は有限・絶対2^52以下、near整数判定1e-6、採用点の元Model検査1e-7を用いる。近傍を狭くしすぎて不能になることはヒューリスティックの失敗であり、本問題の不能や枝刈りには使わない。未知境界metadataは近傍構築を保守的に拒否する。初回コンパイルのusize指定不足は修正し、失敗ログも保持した。主解なしで近傍を作る試験と、20変数の三角形例で元問題に有効な−1の点だけを受け取る試験が成功した。

次は全体試験と、実際にRENSが動く小規模生成MIPの元点/目的照合、その後開発集合で評価する。根LP双対化/零費用固定の候補は別に最終評価中で、本branchの親へはまだ入っていない。これらがmainに入ったら併合して、RENS localの新しい機能を意図せず継承しないよう明示設定して併用を再検証する。

指紋2193f2d4b318b2aa、全284試験成功4無視。変数配置、行数・符号・2冪スケール、費用、offsetを変えた200個の三角形テンプレートMIP（17個以上の整数変数と連続変数を持つ）を最小/最大・2設定で検証し、800出力すべて既知の厳密最適値と元MPSのFraction点/証明検査に合格した。他の主解ヒューリスティックを明示無効にして有効側400回すべてRENSを実行し400点を採用した。これは200個の構造化テンプレートであり、800個の独立した一般MIPではない。初回実験は未対応MIP_OBJECTIVE_ROUNDING_ALLを事前検査で検出しsolver起動前に停止、原ログを残して別出力へ修正再実行した。通常の既定ポートフォリオと併用する選択6問10秒比較を開始した。

通常ポートフォリオの選択6問10秒では、主解・下界の改善なし。rococoと30nではそれぞれ2956/3117変数・10979/11098変数を固定して近傍を探索したが、5node/3nodeで局所不能となり、点は得られなかった。その不能を本問題へ流用せず、両側とも時間制限・主解なしを維持した。rollは固定率条件外、neos-957323は既に主解0があるため未実行、icir/co-100はこの親では根LPが制限に達して未実行。12証明114カットと2点が独立有効。厳密RENS単独の版は今のところ採用根拠なし。少数の固定を緩める別案を検討する場合は、まず同じ総時間予算内で比較し、親mainの新機能も併合してから評価する。

main PR110（零費用固定）を併合し、RENS local内の零費用固定を明示無効にした版8447cb6a07ae0f3dは全289検査成功4無視。同じ200テンプレートの800出力も有効で、有効側400回すべてRENS点を採用。通常のrococo/30n/co-100各10秒ではすべて主解なし、下界も同じ。RENSは3問とも局所不能（それぞれ固定2956/3117、10979/11098、47984/48417）で、局所不能を本問題へ流用しない。近傍を狭めた初版は採用せず、同じ総時間枠で固定の一部を緩める別branchを試す。
