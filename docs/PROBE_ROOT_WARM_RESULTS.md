# 主解probeの根基底再利用

## 仮説

既存の主解専用probeは外側で根LPを解いた後、元モデルからcold startする。大きいモデルではprobeの最大1秒を根LP再計算で使い切り、探索を始められない。根LPの有効カットを含むモデルと、既に得た不変のwarm basisをprobeへ渡すことで再計算を減らす。

## 安全性と範囲

外側がwarm basisを持つ場合に限り、内部のprivate entryから根基底を渡す。基底が無い場合は以前と同じ元モデルからのsolveを使う。行列/境界/費用の構造検査と、基底が使えなければcoldへ戻る既存処理を維持する。親のArcを変異させない。

probeは主解専用の局所探索であり、その境界や実行不能/最適の宣言を外側へ移さない。候補だけを外側の元問題で再検査する。外側の探索木、強分枝の測定、擬似コストもprobeの証明では更新しない。既存の1秒/4096ノード予算を維持する。

## 検証と実験計画

既存209件に、warm根からのprobe候補、外側node_limitと元LP境界の維持、親基底の再利用可能性を検査する1件を加え、210 Rustテストが通過した。

通常/二値/大きめ/混合cut/整数丸め/射影丸めの合成MILP 2700件を実行中。開発用のbinkar10_1、pk1、timtab1、nu25-pr12、neos-911970、roll3000、30n20b8、icir97_tension、enlight_hardを10秒で比較し、krkaを60秒で比較する。すべて変更前後同じCPU・1スレッド・16GiBで、同じPR70の価格付けを含む。holdoutは使わない。

まず保存整数解とカット証明を独立検査し、主解悪化や計算負荷を確認する。有望なら188開発問題を固定snapshotで比較する。採用は未定。

## 初期比較と反例

10組の選択比較はnu25-pr12のprimal54875→54375、他9組の最終primal/dualは同等。20出力の証明と保存整数解10件は独立検査を通過した。nu25の54375点はGMP絶対誤差/公式の両方で有効。初回単独検証は出力ディレクトリを作り忘れて失敗したため、元ログを保持してmkdir後の再実行で検査を完了した。

一律再利用の188比較は実行中だが、eil33-2が1116.990809→1239.694008へ悪化した。root basisを渡さずカットモデルだけを保持する対照版でもこの悪化を再現し、nu25の改善は再現しなかった。したがってカットモデル変更と基底再利用の効果を一つと断定しない。

初回根LP時間はeil33-2が約0.02秒、nu25が約1.26秒で、probeの予算は1秒である。次の版では、実測した最初の根LP時間がprobe全体予算以上の場合にだけカットモデルと基底を再利用する。基準となる時間が未取得なら従来法を保つ。問題名に依存せず、再計算が予算を使い切る場合だけを対象とする。最初の一律版のsnapshotと全188比較は変更せず保存し、条件付き版は別のsnapshot/比較で評価する。
