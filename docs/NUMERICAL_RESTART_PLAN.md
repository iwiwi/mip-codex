# 未証明領域を保留した後にbest-bound領域を選び直す

PR47は未証明のLP不能領域の下界を保持し、残るactiveノードを探索できるようにした。次の仮説は、数値問題が起きた直後だけ別の有望な領域へ探索を移すことである。

MIP_NUMERICAL_RESTART=1では保留後にactive stackの全Entryを既存heapへ移し、次のpopで最良下界のノードを選ぶ。新しく生成する子は要求された探索方式（既定DFS）へ戻す。全ノードのbound/serial/box/warm状態を保った移動だけで、下界・枝刈り・保留の扱いは変えない。再選択できるactiveノードがあった時だけ回数を記録する。既定無効。

再選択と子の優先順、全3探索方式でのノード重複/欠損とmin boundをテストする。同じ10/60秒、1thread/16GiBでgen-ip002の主解/下界/保留件数/最大open/RSSを比較する。範囲を広げることでメモリが増えたり、弱い下界に引かれて主解が悪化する可能性も実測する。良くなければ採用しない。
