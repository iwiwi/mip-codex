# 直接anchorによるk頂点削除・k+1頂点追加

2026-11-18。三頂点版の限定走査に加え、k=4,5,6を同じ汎用手順で診断する。探索に問題名・目標値・他ソルバー点を渡さない。

非選択頂点の選択集合に対する非互換相手が厳密にk個ある場合、その集合を削除anchorにする。その部分集合だけを非互換相手に持つ全候補を集め、候補グラフ上でk+1頂点の互換集合をRust DFSで探す。候補数による棄却だけを行い、発見時は集合全体と元モデルを検査する。探索結果をグローバル境界・最適性へ使わない。全k削除近傍の完全性は主張しない。完了フラグは直接anchorから得られる限定近傍だけを表す。作業100M/走査・期限で中断し、改善時は同じ走査を繰り返す。

n=3..10各60個の480ランダムグラフで、k=2..6の各2400ケースを独立削除・追加集合の全列挙と照合した。各kに必要な改善を持つ2k+1頂点例、期限・作業上限中断も検査した。2テスト合格。本体CLI SHA不変を確認し、別exampleを凍結した。
