# 競合構造上の主解交換

静的次数順の初期独立集合から、1個を外して互いに競合しない2個を入れる交換を行う。各外側頂点の選択集合との競合数を保ち、競合1の候補を外す頂点ごとにまとめる。改善できない時は1対1の交換や少数を外す摂動を試し、競合0の頂点を貪欲に追加する。RNGは固定seed、既知解を初期値や停止条件へ使わない。

最良seedへ保存する前に重複と全ペアのbitset隣接を厳密検査する。許容誤差のあるMPS点検査だけに頼らない。最良の実行可能seedだけをB&Bへ渡し、上界の数学的規則は変えない。根彩色で既に証明できた場合は実行しない。時間枠は全体5%・最大0.25秒、反復は変数数の8倍・最大50000。MIP_GRAPH_LOCAL_SEARCH=1で試し、既定無効。

小グラフの全列挙と制限時の上下界、元MPS/GMP、固定開発18問、sorrell3と別枠open sorrell7で品質/下界/時間を比較する。個別問題名や答えはソルバーへ追加しない。
