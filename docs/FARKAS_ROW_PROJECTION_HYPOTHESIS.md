# 無限幅スラックに対する禁止符号を投影した証拠候補

2026-11-18、main133基準。raw数値失敗への別初期基底再試行は開発4問8出力で改善なしだったため採用せず、別ブランチに保持した。crnaの保存LPでは、最終Farkas候補に無限幅スラックの正乗数が4個あり、最大約2.16e-20だった。大きさにかかわらず、そのままでは矛盾証拠として無効である。

新仮説はMIP_LP_FARKAS_ROW_PROJECT=1、既定OFF。スケールを元に戻したInfeasible候補が既存contradiction検査を通らない場合だけ、各向きについて、非等式行かつslack_upper=∞の正乗数を厳密0へ置く候補を作る。0以外の閾値は使わない。同じcontradictionを全係数で再計算し、厳密な矛盾が認められた場合だけ使用する。通らなければ従来の整数重み修復と拒否へ戻る。期限を維持し、行・境界・許容誤差・枝刈り条件を緩めない。等式行と有限幅スラックの正乗数は投影しない。

元LPのProblem/乗数を変更せず、新Vecを作る。投影候補が受理されても、その後の元MPS係数・境界・実行不能証拠検査は維持する。LPの部分問題証拠を元MILP全体の実行不能宣言と混同しない。成功統計は元LP単位の既存矛盾検査に合格した投影だけを数え、別の元MPS検査結果も記録する。

独立検証：保存crna LPの定義どおりの投影を検査側だけで構成し、binary64を正確な有理数としてFarkas support条件を検査した。投影前は禁止無限幅4件、後は0件でlower>supportが厳密に成立する。投影点・乗数をRustへ渡していない。元MILP全体の実行不能とは主張しない。元データはnumerical-cold-replay-evaluationおよび元作業領域に保持する。

単体検証は、微小正乗数を持つ無効候補から厳密再検査付きで証拠を得る例、可行モデルでの拒否、有限幅/等式/不正/不変乗数の非変更、小さな整数係数の可行boxモデル全列挙に対する偽矛盾0件。次に同じ凍結CLI明示OFF/ONで開発4件各10秒・1thread・16GiBを比較し、返却点をGMP・公式、証明出力を厳密検査する。正の信号があれば全Rust・合成oracle・開発188問へ広げる。

証拠の条件：標準形Ax+s=b、0<=x<=u、0<=s<=vに対し、y・b > Σ max(0,(A^T y)_j)u_j + Σ max(0,y_i)v_i が成立すれば可行点は存在しない。無限幅v_iに正のy_iは許されないため、その成分を0へ投影する。ただし投影でA^T yとy・bも変わるので、上式を必ず全体で再計算する。既存実装は下側と上側の向き付き丸めおよび必要な厳密符号検査でこの不等式を検査する。投影だけで成功扱いにしない。

初期対照：crnaはOFFで53nodes/2.188秒のnumerical_error、ONで59投影を受理し2577nodes/10.001秒のtime_limitへ進んだ。双方primalなし・dual0で、解品質改善はまだない。nidda/glass4/leo1のprimal/dual/statusは同じ。glass4の補助LPでは4投影を受理したが最終数値停止は残った。8出力の証明検査と返却4点GMP・公式検査合格。
