# 正の被覆行の集約による報告下界

単位箱0≤x≤1の元問題で、非負係数・正の下側制約を選ぶ。共通乗数α≥0について、最小化向きに正規化した目的c、定数c0に対し

    c0 + α Σ b_i + Σ_j min(0, c_j − α Σ_i a_ij)

はLagrangian下界になる。係数列和の折点c_j/d_jを並べ、区分線形凹関数の傾きが非正になる候補を選ぶ。候補選択の浮動小数誤差には正しさを依存させず、既存Certifierで元入力区間から外向きに下界を計算する。報告用にさらにnext_downを適用する。

証明は選択行番号、αのIEEE754ビット列、正規化下界を含む。独立Python検査器が元MPSをFractionで読み、正確なαと有理数式を再計算する。元箱が正確に0/1でない場合は対象外。最大化は目的符号を反転して扱う。

まず結果表示だけに使い、探索順、枝刈り、最適・実行不能の判定には使わない。計算は根LPより前、全体予算の5%かつ0.25秒以内で試みる。サイズ上限と期限を確認する。初回V1は係数100万まででcygnetの約490万非零係数を対象外にした。この誤った接続範囲はログを保存し、診断費用を確認した上で次版を評価する。

診断は開発188件だけに実施し、holdoutモデルは読まない。対象40件の全下界が元MPS有理数検査で有効。cygnetは9567/64、Rust外向き値149.48437499942762、モデル読込後0.107秒。200小例は全列挙最適値以下、200証明有効/1000改ざん拒否。これらは下界の妥当性であり、最適性証明や新記録の主張ではない。
