# 多様化した局所探索の適応的予算を採用

多様な再構築を繰り返す際、全体5%・最大2秒、最大128n/500000反復を許し、16n（最低256）反復改善しない場合は早く終了する。以前の最大0.25秒・8nより延ばすが、停滞した問題では全時間を消費しない。予算・反復上限・最終改善反復・終了理由を結果へ残す。最良主解の厳密な全ペア検査と上界・枝刈りの数学は維持する。
