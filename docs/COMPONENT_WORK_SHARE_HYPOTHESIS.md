# 成分間で残りの仕事量を配分する

親はmain PR95/FP1bc790cdcc13dc62。成分修復は60秒215/300秒213を得たが、300秒は公称15秒の前に1B soft workへ達して約11.25秒で止まった。独立helper15秒210より弱かったのは構築・検証・資源制限の差もあり、単に同じ実装とは主張しない。

新案は総時間5%/30秒・総仕事量1B・全候補の元問題検査を保ち、各成分の開始時に「残り仕事量/残り成分数」を局所soft上限へ割り当てる。時間は従来どおり残り時間/残り成分数。同じ総量で後ろの成分にも探索機会を残す。既存公開improveは従来配分のwrapperとし、追加API improve_sharedとMIP_COMPONENT_WORK_SHARE既定falseで対照する。問題名・既知の解・成分ごとの答えは使わない。

初期は60/300秒対照、元MPS点検査、全列挙小例を通し、既存215/213を悪化させる場合は採用しない。soft上限のchunk超過は実測を保持する。全体優位・新記録は未達。
