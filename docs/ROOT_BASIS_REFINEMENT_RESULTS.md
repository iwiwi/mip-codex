# 数値失敗時の基底残差補正：新しい根点を確認

再分解直後の比率検定で基底値が既存FEASから外れた場合だけ、厳密積和で残差を再計算し、同じLUで最大3回補正する。非基底値を変えず、元の基底境界と比率検定を満たし、正規化残差が悪化しない候補だけ採用。期限切れ/失敗は元点を保持。元単位・元MPSの検査と不能証明の検査は省略せず、許容差も変更しない。

過去PR54はglass4/app1-1の最終結果が変わらず不採用だった。今回の開発188問の追加診断で、9根numerical_errorのうち8が同じ比率検定箇所だったため対象関数と2テストだけ再評価した。過去の失敗候補を受理する処理や後段certificateの補正は取り込まない。
