# 深い節点の彩色修復

Prosser (2012), https://doi.org/10.3390/a5040545 の数学的な色クラス交換を参考に独立Rust実装。外部コードは移植しない。既存docs/GRAPH_NEXT_HYPOTHESES.mdの未実装仮説を評価する。

根の彩色は維持する。深い節点で枝刈りに必要な色数を超えたクラスの頂点vを低いクラスへ移す。隣接がなければ直接移動、1頂点wだけならwを別の低い非隣接クラスへ移す。両移動可能性を確認してから変更し、各クラスの独立性を維持する。各節点4096隣接検査で打切り、その時点の正しい彩色を使う。途中の期限到達は従来同様探索中断とし、安全な根残上界を維持する。既定無効 MIP_GRAPH_COLOR_REPAIR。全列挙・元MPS証明/GMP・実測時間で判定する。
