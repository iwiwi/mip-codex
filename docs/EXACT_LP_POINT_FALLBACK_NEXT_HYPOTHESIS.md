# 元十進係数でのLP点検査を正確に再計算する次案

未実装の仮説。区間RHS対によりleo1のNaN行を回避しても、保存stderrに「Original LP check failed: row R0000001 violates bounds or loses precision」が残った。row0は自由連続変数C0000001（係数1）と多数の小数項を含む目的定義等式。原因は実際の元十進残差なのか、保守的な係数包絡の幅なのか、まだ切り分けていない。

次に行うのは、失敗時の元座標LP点を診断用に保存し、元MPSのFraction計算で残差・境界を測ること。目的値や既知解を探索へ入れない。実残差が要求精度を超えるなら回収案は棄却する。十分小さい実残差なのに区間幅だけで停止している場合に限り、元十進トークン・出力点の厳密有理数で点を再検査するRust経路を検討する。

許容差や整数境界を緩めない。元モデルのソース一致・元行prefix一致を保ち、真の違反・欠けたトークン・期限切れ・サイズ上限をfail closedとする。採用可否はまだ決めない。LP点の可行性と下界/不能性の証明を分け、元係数のdual検査・枝刈り・最終有理主解検査は維持する。LP点が検査を通るだけで最適・不能と宣言しない。

これは現行のRHS対機能とは別の次案であり、現行開発188比較へ混ぜない。現行の改善判断とアーカイブを先に閉じる。既存primal_witnessの有理算術・Source保護は再利用候補だが、現状の変数4096/非零32768上限と6731変数の対象との違いも診断資料へ残す。
