# 根の主解に既存の目的下降を適用する

既存box_searchにある、活動量と列接続を使う単変数の目的下降を、根の修復が発見した整数点にも適用する。初期点は元問題で検査し、候補は元問題の検査、有限目的、目的の単調性、元入力区間からの目的誤差上限を確認してから受理する。非有限値や桁落ちで精度を証明できない場合は元の点を保持する。

まず既存の目的上限制約修復と同じ純二値・単位費用・定数0だけに接続する。下降で改善したときだけ、より重い目的上限制約修復を省略する。改善しなければ既存処理に戻る。既定無効、MIP_ROOT_PRIMAL_DESCENT=1で対照を行う。上下界/最適性/不能を新しく宣言しない。

独立診断FPa2b71259f5959ce1はcygnet220→218を0.097213213秒で得た。既存の目的制約修復は同じ218に0.515773291秒を要した。SP97/tbfpは同じ点、0.00588/0.00846秒。これは局所処理の測定であり、全MILPの速度改善ではない。各source/ELF/SHAと入力/起点SHAを実行前に保存した。
