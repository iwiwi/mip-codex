# 座標修復のbreakout実験

既存の修復は正の違反減少がある座標だけを変更する。x+y>=1、x=y、x,y二値の00では、片方の変更の改善と悪化が等しく、実行可能な11へ進めない。局所最小で違反行の重みを倍にし、同じ座標探索を再試行する。重み変更は1回のsearchで最大32回、既存の時間/仕事量枠内とする。search終了時に元の正規化重みへ戻す。

MIP_REPAIR_BREAKOUT=1で有効、既定無効。候補は既存の元問題/桁落ち guardですべて検査し、主解だけに使う。枝刈り・下界・実行不能の根拠にはしない。小問題の全列挙/既存2700合成/32数値回帰、固定開発18問のprimal/dual/時間と保存解の独立検査で採否を決める。
