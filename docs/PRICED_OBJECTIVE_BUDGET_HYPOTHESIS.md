# 改善系列への長時間予算配分

既存目的cut修復は共通5%/最大2秒/100M work/64 seedで停止する。追加30秒の独立診断はさらに良い点を得たため、最初の既存予算内に改善した系列だけ共通5%/最大30秒/合計1B work/1024 seedへ進む案を検証する。延長後の上限は追加分ではなく同一phase全体の上限とし、全体deadlineを越えない。改善0の系列は16 seedと既存期限/100M workのまま停止する。

10秒など全体40秒以下の枠は5%が2秒以下なので延長なし。60秒では最大3秒、300秒では最大15秒、3600秒では最大30秒。これは資源配分変更であり、同条件のprimal/dual品質と時間損失を対照し、元MPSの独立検査が通るまで採用しない。モデル名、native解、既知最適値は条件に使わない。

元点保持、元Model検査、目的誤差区間guard、4e−8改善margin、期限/workの払い戻しなし、証明・枝刈り・不能/最適終了への非干渉を維持する。既存APIは延長なしで動作を保持。CLI MIP_ROOT_PRICED_BUDGETは実験既定false、継続flagが有効な場合だけ延長する。短期の全188対、60/300秒対照、元MPS監査、成功/失敗系列の停止条件試験を行う。
