# 非一様費用被覆の射影乗数更新

単位費用cygnetで改善しなかった旧劣勾配診断を、そのまま採用しない。非一様費用では一様乗数の根下界が弱いため、元の費用を使い、一様row-rayを初期乗数として非負乗数を更新する独立診断を作る。元boxのLagrangian下界は offset+sum(y*b)+sum(min(0,c−A^T y))。どの非負yでも成立し、浮動計算の近似値は証明と扱わず、既存Certifierの元入力区間で検証する。元MPSを独立Fractionで読み、IEEE乗数を正確な有理数へ変換して照合する。

自作60秒の整数点だけをPolyak型stepの目標値に使い、step係数.1/.5/1/2を共通に診断した。2秒ではSP97の係数2が644681855.5522825、SP98が490149267.00974834。8件すべて元MPSの独立有理数検査有効。library FPce227d3d2805b2d4と全sourceを参照し、helper source/ELF/SHAを実行前固定。native解・既知値・モデル名は条件にしない。

自作10秒の整数点を使う追加診断は共通係数2で、0.1/.5/2秒を比較。SP97は542157852.5550075/620535478.364168/645091907.4112451、SP98は399725206.95682645/460240554.47207737/491641751.66609985。証明構築を含む実測は各予算を約0.011/0.017秒超えた生値を保持し、独立有理数監査中。主ソルバーへはまだ未統合。候補採用時は元点・既存下界保持、全体deadline、厳密証明を必須にし、まずreport-onlyとして比較する。

短期6件も全件元MPSの独立有理数照合有効。次のpriced-row-subgradient branchでreport-only実装を試作し、元モデル証明をJSONへ出力する検査器も追加した。こちらは別FP/別実験として記録し、現在の予算配分PRへ主ソルバーの下界実装を混ぜない。
