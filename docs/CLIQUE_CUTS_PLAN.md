# 二値競合clique cutの実験

元の1行を使った2変数coverの証明を辺として集める。正負を持つliteral（xまたは1-x）について、すべてのペアが同時に1になれない集合ならliteral和<=1が成立する。これは各ペアのcover証明を独立に確認して検査できる。既存のcover/整数除算cutと区別して証明・統計を保存する。

辺の証明は元MPSの境界/行だけから作り、追加済みcutの循環証明には依存しない。Rustで辺と最終cliqueの全ペアを再検証し、Python Fractionも元MPSから別途検査する。負のliteral、混合連続項の元境界射影、欠けた辺、重複変数、偽の証明を検査する。

既定は無効。根の既存cut時間枠内で、行長128/辺数20000/選択32literal/seed128/仕事量上限を設ける。固定seedの合成と全列挙、開発18問で解品質・下界・時間を比較して採否を決める。holdoutを調整に用いない。mainの固定列省略は有効のまま。
