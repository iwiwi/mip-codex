# 制約結合による証明用有限箱

個別の元制約から変数の有限上限を導けなくても、非負の行結合から導ける場合がある。有限な上側（なければ下側の反転）の和を作り、欠けた境界に必要な係数符号を持つ行を最大8回追加する。重みは非負で有限な候補に限る。結合の全係数/右辺を元小数係数の区間で外向き計算し、全変数の最小寄与を包囲できた場合だけ境界を導く。導出失敗時は箱を変更しない。証明器内部の欠けた根変数境界だけを補い、探索boxやLPは変更しない。

最終判定は元問題に対するCertifier.bound>0である。候補生成の丸めや符号を信頼して枝刈りしない。MIP_AGGREGATE_INFEASIBILITY=0/1で比較でき、最終版は既定有効。
