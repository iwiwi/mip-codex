# 整数回数による分数クリーク被覆上界

## 変更と証明

認識済みの一様目的二値競合グラフで、重なりを許す競合クリークの被覆から上界を求める。既存彩色クラスを初期被覆として保存し、時間・メモリ・個数・深さを制限した独自の極大クリーク列挙とgreedy拡張で候補を生成する。列挙未完でも安全であり、列挙完了を最適性の根拠にしない。

頂点価格の和が大きいクリークを選び、その頂点価格をexp(-1)倍する独自ヒューリスティックをlazy heapで実行する。既存最適化ライブラリへ委譲せず、native LPの重みや解も使わない。生成時間は総時間枠の2%、最大0.5秒、その1/4をクリーク構成に割り当てる。最大20000クリーク、最大500000反復。入力名による例外はない。

クリークCの正整数選択回数をc_C、総数をT、全頂点の最小被覆回数をk>0とする。独立集合Sではk|S|≤Σ_C c_C|C∩S|≤Tなので、|S|≤floor(T/k)。価格の浮動小数値は証明に使わない。最終クリークの全組対と整数被覆を再検査し、既存彩色より小さく既存主解以上の場合だけ採用する。

各探索接頭辞Pでも、Pに交わるクリークだけの重み和T_PとP上の最小被覆k_Pでfloor(T_P/k_P)を得る。彩色接頭辞上界とのminを使う。JSONに元変数番号のクリークと回数を保存し、独立検査器は元MPSから競合辺・被覆・上界を再計算する。探索木の全分枝の独立再生は行わない。

## 開発比較（暫定）

同一binaryの`MIP_GRAPH_FRACTIONAL_COVER=0/1`、1thread/16GiB、前処理前MPSのGMP/公式解検査と独立グラフ証明検査を実施。sorrell7はBenchmark v2外の探索用入力で、240問の成績に加えない。

|入力/制限|従来 主解/下界|変更後 主解/下界|
|---|---|---|
|sorrell7 15秒|-193 / -379|-193 / -242|
|sorrell7 60秒|-197 / -379|-197 / -241|
|sorrell3 15秒|-16 / -24|-16 / -24|
|sorrell3 証明完了|-16 / -16|-16 / -16|

sorrell7 60秒の相対gapは約92.4%→22.3%。既存の同資源native60秒測定（PR38から再掲、今回は再実行しない）はHiGHS -186/-231、SCIP -152/-583.148246391059、GLPK -21/-479。Rustは主解で優位だが、HiGHSの下界231は241より強い。公開最良解198超えも、sorrell7の最適性証明も達成していない。

sorrell3は同じ6042153節点。今回の一組では18.82409→19.36069秒、被覆の追加0.5秒で約2.9%遅い。候補20000個でも被覆上界は改善せず、その負担を速度改善と呼ばない。sorrell7の60秒では4340候補、136562反復、検証済み上界241、被覆処理約0.501秒。

初版はgreedy構成が予算を使い切り列挙0回、sorrell7上界306であった。構成順序を変更し、pivotをP∪Xの立ったbitだけから選ぶ版で242/241となった。初版のソース・結果・診断用native LPを含む全試行を保持する。

## 検証（途中記録）

5頂点の全1024グラフで、整数被覆と全接頭辞に対する全実行可能部分集合の上界を全列挙照合。極大クリーク集合も全列挙と一致し、重複頂点・非クリーク・未被覆・重複順序の不正入力を拒否する。初版Rust全体テスト成功。最終構成順序のCLI200モデル×6制限=1200件成功、破損証明7410件を拒否（初版も別途同数成功）。固定開発18問と最終既定値の検査は継続中。
