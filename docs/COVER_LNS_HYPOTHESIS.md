# 自作Rustの厳密な制限近傍探索・私的主解仮説

本体srcはE5不変、別supportコピーだけで試す。自作GMP検査済みseedの選択点を32/64/128個程度、競合近傍をたどって外し、残りの選択点と両立する点だけ（最大1024点）を自由にする。元の厳密packing認識から得たinduced graphを、同じ自作Rustの彩色/branch探索で初期主解付きで解く。1近傍2秒/200k節点、全体600秒/200近傍。問題名・既知目的値・外部解は使わない。

自由点と保持点の両立を厳密に確認し、制限問題の点だけを元モデルへ戻す。制限問題の境界/optimal/infeasibleを元の大域主張に移さない。内部候補は全strict clique/Model.check0、改善した点だけ元JSONと制限MPS/点/変数mappingを出し、最終点も出力。出力全点はPython driverから元/制限MPSの独立GMPで検査する。

200個の9頂点以下random graphでseed付きcore解を全列挙と比較し、さらに200個で制限集合の全実行可能部分集合を元へ拡張して可行性を検査する。これらは元点のGMPに加える検査である。本体移植/再現まではprivate成績のみ。
