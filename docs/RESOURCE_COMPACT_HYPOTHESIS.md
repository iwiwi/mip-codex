# 目的0の局所実行可能性MIPを選択行の列だけへ圧縮する

main PR115（FP433c14477b492b66）を親にする独立候補。既存resource-primalは根LPが資源制限で主解なしのときだけ、違反原行を足す目的0の局所MIPを解く。現在の選択行に現れない非固定列は局所目的も厳密0で、箱内の現在候補を保てば局所実行可能性に影響しない。それらだけを局所MIPから外し、選択行の列を元index昇順に写す。原行/係数/境界/十進metadataの値を変えず、行のindex対応だけを写す。全固定列は残し、既存fixed-columnsと明示無効/統計を保つ。

局所pointを元の全変数へ復元し、取り除いた列には直前の値を保持する。後の違反行追加でその列が使われれば次の局所MIPに再導入する。全元制約/境界/整数性/有限目的と既存の大域下界整合性を通す点以外を返さない。局所不能/最適/下界/基底/擬似コストは大域へ渡さない。予算/呼出し条件/行の追加順は変えない。研究flag MIP_RESOURCE_PRIMAL_COMPACTは初版既定無効。compact_calls/columns/removedを報告し、実際に処理が動いたことを確認する。
