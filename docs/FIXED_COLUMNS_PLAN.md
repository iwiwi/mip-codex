# 元問題の固定列をLPから省く実験

元問題の両境界で固定された連続変数、または元十進境界の全外向き区間で同じ整数に限られる整数変数だけを省く。子節点で初めて固定された変数は省かず、warm basisの列構造を保つ。既存の厳密なRHS/目的シフトを利用し、目的定数を二重に加算しない。全列が消える場合も正常なLP判定を行う。

実験時は既定無効としてMIP_FIXED_COLUMNS=1で明示して比較し、固定列数と有効フラグを保存する。適格列ゼロの場合は節点ごとの適格性検査を省く。入力の巨大整数、元十進数の不確実性、整数singleton、不可能な定数行を両LP engineで検査済み（Rust152テスト成功）。

次はreleaseで合成2700、根LP300、変換22と巨大整数10解、固定18問とmarkshare60秒を比較する。保存解を元MPSに独立検査し、主解/下界/探索量/時間を比較して採否を決める。改善がなければ実験ブランチとして保持する。

固定18問のprimal/dualが同一、28保存解/140cutsの独立検査が全件有効。30n20b8の50節点を同じ下界まで解く3回中央値が5.064→4.140秒、根だけは0.08817→0.07579秒となったため既定で有効にする。対象列ゼロのmarkshareは同じ1,486,619節点で35.642→35.683秒、速度改善は主張しない。MIP_FIXED_COLUMNS=0で比較用に無効化できる。
