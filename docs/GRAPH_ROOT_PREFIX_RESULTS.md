# 探索順を保つ根prefix上界を採用

PR38で根の最小色数へ探索順を変更すると、sorrell3の証明時間が約18.3→20.6秒へ悪化した。元の根探索順を維持し、各prefixに制限した複数の正しい彩色の色数の最小値を上界とする。根上界を強めながら探索順の変更を避ける。深い節点の彩色・分岐は変更しない。根順と完成候補彩色を保存し、独立検査器も各prefix上界を元MPSから再計算する。

## 1thread・16GiBの比較

同じバイナリで機能を切り替えた。sorrell3の60秒上限は全回optimal-16/-16。旧はCPU2/0、新はCPU3/1で測定し、各コアを専有した。入力とバイナリのSHA、実行コマンド、CPU/RSS/終了状態を保存する。

追加の60秒sorrell3 native比較はHiGHS主解-16/下界-20、SCIP -11/-76.5、GLPK -1/-255でいずれも時間制限。本実装はこの構造で先に証明したが、全体優位は主張しない。全件native v2は別の不変snapshotで継続している。既知の最適値や解を探索には渡していない。

独立検査器は元MPSのFractionから構造と候補彩色の正しさ、実際の根順の順列、残prefixの色数上界を検査する。完了した根分岐の探索木自体は全再生せず、最適性を完全に外部再証明したとは主張しない。小問題の全列挙・既知の公式最適値との照合と区別する。

局所探索の単なる時間増加はPR39で不採用とした。sorrell3/7の15/60秒の主解/下界が不変で、sorrell3の証明時間を約2秒消費するだけだった。ソースと失敗を含む全記録は閉じたPR39のgraph-local-effortブランチに保持している。
