# 資源制限後の主解を直接修復して改善する仮説

2026-11-17、未採用の診断専用案。既存のpriced_objective_repairは全変数binary・非負目的・10万変数以下に限る。resource_primalで得た混合型の境界点には適用されず、先の局所MIPによる端点同時固定試作も候補なしだった。

元点に正規化した目的改善行を1本追加した作業モデルを作り、既存のRust座標修復Repairを直接呼ぶ。整数・連続の扱いはRepair既存の処理を保持し、目的係数の符号や最大化は正規化する。探索対象の局所作業モデルは原モデルを変更しない。返った点は元問題の実行可能性と目的改善を再検査する。目的改善行の不能・数値状態や下界を原問題に転用しない。

最初は例プログラムのみで、保存済みの開発用主解から3秒、修復仕事量上限を指定し、原MPSのGMP検査まで実施する。準備時間込みのwallも別記する。改善がなければその事実を記録して棄却する。本体への有効化やMIPLIBの個別調整は行わない。
