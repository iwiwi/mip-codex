# 実装と出典

本体の最適化はRustで実装。MPSを有界変数の等式形式に変換し、実行可能なスラック基底がない行には人工変数を入れる。第1段階で人工変数和を最小化し、第2段階で元の目的関数を最小化する。自由変数は正負2変数に分解する。整数変数は分枝限定で床・天井に分岐する。

LPは疎な列形式、基底LU、積形式のeta更新を使用する。64 eta更新ごと等で再分解し、最適終了前に再分解と再計算を行う。faer 0.23.2（MIT、https://github.com/sarah-quinones/faer-rs）は汎用疎LUと線形方程式の解法だけに使用する。LP/MIPの最適化APIは使わない。

既存ソルバーコードの翻訳・取り込みはしていない。二段階単体法、改訂単体法、積形式逆行列、Harris型比率検査、分枝限定は標準的アルゴリズムとして実装した。SCIP/HiGHS/GLPKは比較・検証プロセスだけで使う。比較専用GLPKドライバはGLPK 5.0公開APIを使い、GPL-3.0-or-laterで提供する。

現時点の限界: 前処理・カット・強分枝・ウォームスタート・本格的なヒューリスティクスなし。数値計算は浮動小数点で、厳密証明ログなし。LP緩和の非有界性はMILPの非有界性として宣言しない。数値失敗・資源制限は未解決として記録する。
