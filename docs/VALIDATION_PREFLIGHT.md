# 測定開始前に独立検査器を確認する

別worktreeで潜り探索を試した際、無視対象のcompiled checkerを配置し忘れ、返却optimal点1657件のGMP検査がvalid=Noneになった。失敗を隠さず全入力/解/ログをPR23のflexible-diving branchへ保存し、checkerをコピーして独立照合をやり直した。訂正2200合成は失敗0、訂正18問の28主解もGMP/公式とも全有効。潜り探索の候補自体は利益と悪化が混在したため採用していない。

同じ事故を防ぐため、開発smokeとsyntheticはabsolute checkerが無い場合、出力ディレクトリ作成やケースの実行より前にエラー終了する。MIP_ABSOLUTE_CHECKERを指定した場合はその場所を尊重する。validatorの単独呼出しでは従来どおりvalid=Noneを返し、未検証と誤答を区別する。smokeのexperiment.jsonには使うcompiled checkerのSHA256も追加する。

3件のpreflight回帰と既存validator回帰で確認する。最適化アルゴリズム/既定設定の変更は含まない。稼働中のbaseline snapshotには適用せず、結果も書き換えない。コード変更による性能向上は主張しない。

## 実行ファイルの作業ツリー照合

mainへ戻って既存Cargo cacheを使った際、共有targetの最終実行ファイルに別worktreeの潜り試作が残る現象も、測定前の0秒診断で検出した。未実行の測定を開始せず、ビルド元を返す`build-info`コマンドを追加した。smoke/syntheticはcompile時のCARGO_MANIFEST_DIRが自身のrootと一致することも開始前に検査する。smokeはbuild-infoをexperimentへ保存し、syntheticもbuild-infoとbinary hashを保存する。

6件のpreflight回帰は、他worktreeのfake binaryの拒否/正しいrootの受理/検査器パス指定/検査器欠落のsynthetic停止/smoke停止を含む。0秒のprotocol smokeで実際のmetadataも確認する。共有targetを複数sourceの出力先として使う場合の最終binary取り違えを、結果の収集前に検出する。今後はworktree固有のtargetを必須とし、build-infoを照合する。

最初のorigin確認だけの0秒smokeでは、binaryのsource_directoryはmainでも、cached libraryが別worktreeという混在を検出した（120053、nodes0、採用しないprotocol試験）。libraryにもcompile時のディレクトリを定数として埋め、両者の照合を必須にした。fake mixed library拒否も6回帰に含む。再ビルド後は両ディレクトリがmainで一致することを確認した。過去の性能runのsource/flagと生ログは変更していない。
