# 元十進モデルの有理実行可能点証拠

2026-11-17。保守的な最適性撤回の後続研究。二進値の点を元制約に対して厳密確認する安全性ガードは、3y=1や十進固定値0.3でも撤回する。元十進係数・境界の非二進表現だけをパーサで保持し、近傍の有理点を復元すれば安全性を緩めず撤回を減らせる。
