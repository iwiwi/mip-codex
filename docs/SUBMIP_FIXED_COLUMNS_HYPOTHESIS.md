# 子MIPで利用者の元の固定列設定を再評価する

main PR110を親とする独立試作。親に元から固定列がない場合、solve_seeded_warmは実効fixed_columnsをfalseにして不要な固定判定を省く。この実効LimitsをRINS/終端近傍/probeがcloneすると、近傍Modelで新たに固定された列があっても固定列除去が無効のままになる。

MIP_SUBMIP_FIXED_COLUMNS=1では、3種類の子MIPを作る際にfixed_columnsを利用者が要求した元の値へ戻し、子のsolveで固定の有無を再評価する。既定無効の比較候補。利用者がMIP_FIXED_COLUMNS=0を指定した場合は無効を保つ。任意の分枝子の列を途中で除かず、その子MIPのModel上で最初から固定された列だけを標準化で除くため、その木のwarm列配置は安定する。数学モデル・元問題の点検査・枝刈り・許容幅は変えない。

結果submip_fixed_columnsには全子呼出しで除去対象となった固定変数数の総和を保存する（全体で異なる変数の数ではない）。単体検査では元の20変数に固定がないモデルへRINSを適用し、旧設定0列→新設定17列を除き、両設定で元問題に有効な目的−1の点を得た。明示的な固定列除去無効を指定した場合は新設定でも0列で、親の境界は変わらない。

RENSの不能方向ヒントとは別の変更として、全体検査後に既存のRINSが動く開発問題で比較する。まだ採用しない。
