# 対称ペアに制限した主解探索

元uniform binary packingグラフの頂点を自然な変数順に並べ、順序反転を対合候補とする。全辺・非辺で自己同型を厳密に検査する。固定点と内部競合のあるペアを除き、残りの2頂点軌道を選択単位とした制限グラフを作る。軌道間に元競合が一つでもあれば制限グラフに辺を置く。各軌道の目的重みは同じ2倍なので、既存Rustグラフソルバーを使える。

制限問題の実行可能点を元頂点へ展開し、全元制約のGMP検査と厳密競合検査を通過した点だけを主解候補とする。制限問題は元問題全体を覆わないため、双対境界・最適性・実行不能を一切移さない。初期試作の変換はPython、最適化は採用済みmain125の凍結Rust340。効果があれば主ソルバーへ入れる前に変換と呼出しもRustへ移す。問題名や目標解値を最適化ルールや停止条件へ固定しない。

追加の候補として、二進ラベルのbit順反転と、その反転＋補数も全辺/非辺で自己同型を照合した。固定点を除く同サイズ軌道で制限問題を作り、展開後に安全な単頂点追加を3つの一般的な順序で試した。さらに自作点の二部unionで最大matchingを自作実装して厳密に再結合し、3親unionの制限問題を自作Rustで解く。いずれも原点だけを検査し、全体の双対証明は主張しない。
