# 未証明のLP不能領域を保持し探索を継続

元問題へのLP不能証明が取れないノードを解決済みとせず、継承下界を保持して別のactiveノードを探索する。集約下界がincumbent以上になった場合だけ集約全体を枝刈りできる。最終global dualには保留下界も含める。保留が残ればnumerical_errorを維持し、時間切れ等はlp_search_terminationへ別保存する。一般の数値異常・LP非有界・resource_limitの停止は変更しない。

## 検証

166Rustテスト成功。新しい下界集約テストは、有限incumbentがない場合に除かないこと、一括枝刈りの条件、-inf下界の保持、次の保留追加を確認した。2700合成MILP、300根LP、32数値回帰に失敗0。変換証明ができない14例は未解決のまま保持する。

固定開発18問はgen-ip002の主解だけ改善し、他は主解/下界/status一致。PR45の同じCPU/上限/メモリの保存結果との比較で速度評価には用いない。新旧保存26点・134cut/36検査記録、直接10/60秒新旧4点、反復3点、native6点の計39点は元MPSのGMP・公式検査で有効。GMPは制約/境界/整数性が絶対基準、目的値は既存の相対基準であり、厳密再計算値も保存する。根/カット等の43Rust検査記録も成功。完了済み探索木の全外部再生とは区別する。

保留は下界最小値と件数だけの定数メモリ要約で、全boxを保存して再試行する機能ではない。個別に枝刈りできる領域があっても最小下界が残る間は集約全体を保持するためpending件数は保守的な保持件数。MIP_DEFER_INFEASIBILITY=0で旧挙動へ戻せる。次は数値失敗後の探索順や、LP自体の数値安定性を改善する。
