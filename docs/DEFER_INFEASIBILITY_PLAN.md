# 未証明のLP不能領域を保留し他のノードを探索する

gen-ip002は約37993節点でLP不能を元問題に証明できず、正しくnumerical_errorとして全探索を終了している。主解の改善余地を残すため、MIP_DEFER_INFEASIBILITY=1ではその領域を解決したと扱わず、既存の継承下界を保持して別のactiveノードの探索を続ける案を検証する。既定無効。

保留領域の下界の最小値と件数を定数メモリで保持し、最終global dualはactiveノード・終端下界・保留下界の最小値とする。保留領域の最小下界が有限incumbent以上なら全体を一括で枝刈りできる。個別に枝刈りできる保留領域があっても、最小下界が残る間は集約全体を保持するため、pending件数は保守的な保持件数である。再試行用の全boxは保存せず、解決したと仮定しない。

保留が残ればstatusはnumerical_errorとし、lp_search_terminationへtime_limit/node_limit/active_search_complete等の実際の探索終了理由を別保存する。保留があるのにoptimal/infeasibleへ変換しない。観測・保持・一括枝刈り件数、下界、下界が-infかを結果へ記録する。既存のinfeasibility_proof_failuresも維持する。単に失敗を時間制限へ名前変更して成功扱いしない。

変更対象は元問題へのLP不能証明が取れなかった分岐だけ。一般の数値異常、LP非有界、resource_limit等は従来の停止を維持する。元のbox/certificate検査も省かない。debug dumpを要求された場合は連続失敗で上書きしないよう一意なsuffixを付ける。

下界集約・-inf保持・全体枝刈りのテスト、2700合成MILP/300根LP/32数値回帰、同じ10/60秒・1thread/16GiBのgen-ip002新旧比較、固定開発18問と元MPS検査を行う。改善があっても、証明できない限り未解決の分類を保つ。問題名や既知の答えはsolverへ埋め込まない。

保持する下界は内部の最小化座標である。Resultのdeferred_infeasibility_boundは元の目的方向へ戻し、最大化なら保留領域の上界を示す。unboundedフラグはそのboundが有限でないという意味で、MILP非有界の証明ではない。gen-ip002の目的係数とsenseを反転した同値問題も50000節点で比較し、元と同じ点・反対符号のprimal/dual/保留boundを確認する。
