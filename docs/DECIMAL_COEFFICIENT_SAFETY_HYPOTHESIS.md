# 小数係数の丸めと元問題の下界

## 再現した問題
main d11f3c9b (source fingerprint cb0ba03a36c3f07e) は、連続変数 0≤x≤2、目的 min −x、制約 0.99999999999999999999 x≤1 に optimal、目的値 −1、下界 −1 を返す。元の有理数での最適値は −100000000000000000000/99999999999999999999。したがって下界は厳密に非保守的である。目的値の相対誤差許容と下界の正当性は別に検査する。

## 仮説と実装
字句の小数が binary64 で整数に見えても、整数係数の厳密性を認めない。係数が厳密でない元MPSについて、LPの双対乗数を元の行へ戻し、既存 Certifier の係数・境界・目的関数の区間演算で下界を再構成する。証明できなければ numerical_error として未証明下界を採用しない。元の連続変数境界の外向き区間を利用する。有限メモリの制限を維持する。

疎LPに加えて密LPも、内部で検査済みの乗数を呼び出し側へ返す。既存公開APIは維持する。最適化ライブラリへの委譲、数値許容値の緩和はしない。

## 現時点の検証と制限
- 初版のparser修正のみでは問題は直らなかった。ログを保存。
- 下界再構成後、上記例は −1.0000000000000004 を返し、厳密な分数比較で保守的。
- 整数変数と連続変数の等式例は従来どおり最適性を撤回。
- 新規3テスト成功。初回全テストで密LPの乗数未返却を検出し、返却経路追加後の対象10テスト成功。
- 全333テスト成功、4件ignored。216解析例の修正前94非保守的下界に対し、修正後0。両版計432点が独立GMP検査成功。有限でないboxでは区間stationarityを証明できず終了する可能性があり、性能・求解率への影響は未評価。
- 次: 分数解析解の系統的検証、元問題の独立GMP点検査、小規模MILP・親下界証明、開発188問比較。未採用。

初版 a273febe33 / a6cac75c0f46dffe は、解析216例のうち自由変数を含む108例で数値終了した。元の行から区間演算で有限境界を導く既存 infer_finite_box を目的関数の Certifier にも適用した a301162741 / 38b0a4315610cc1a では、216例すべてを最適判定し、下界の厳密な分数検査も全て成功。密LPも同じ216例が全最適・全下界保守的。修正前の非保守的下界は疎94/密108例。両エンジン両版864点を独立GMPで検査済。
