# 局所不能後に固定を一部緩めるRENS試作

RENS初版は主解なしのrococo/30n/co-100で近傍が数nodeで局所不能となった。最初の近傍が不能で点を返さず、総予算が残る場合に限り、一度だけ固定を緩めて再試行する別branch。MIP_RENS=1とMIP_RENS_RELEASE=1が必要で、両方既定無効。

元のLPでfractionalな整数変数と同じ行に現れる固定整数変数を数え、共有行が多い順（同点はindex由来の固定hash）で最大5%・最低1個を選び、その変数だけを元の境界へ戻す。問題名・既知解・比較側の答えは使わない。最初の80%固定率判定は維持するが、緩和後の固定率はその分下がる。隣接行走査も含め、初回と再試行は同じ全体10%・最大1秒を共有する。局所Time/iteration/numericalでは再試行しない。

局所不能は再試行のきっかけだけで、元問題の枝刈り・不能・双対下界には使わない。点は元問題に対する独立の採用条件を維持し、親Model・warm基底・pseudocostは変えない。試行回数、緩めた数、局所不能数、最後の状態、全node/LP/時間を統計へ保存する。

3単体検査成功。三角形のLP点では整数のz=0固定で丸めが不能になる例を作り、fractional変数と結合するzだけを緩めると、2回目の近傍から元問題で有効な目的0の点を得ることを確認した。元のz境界が変わらず、局所不能の後でも元問題を不能としないことも検査する。元のRENS定義はRENS_INITIAL_HYPOTHESIS.mdの引用先を参照。これは独立Rust実装への追加案で、まだ採用判断前である。

指紋eb47763fe5ae59e8、全290検査成功4無視。200テンプレートの半数には厳密な丸め近傍だけが不能になる追加行を設けた。最小/最大・strict/releasedの800出力は全て元MPS Fraction点/証明検査と既知の厳密最適値へ合格。RENS呼出し計1000回・採用600回で、緩和設定では全400方向で点を採用し、追加行のある200方向は2回目の呼出しで採用した。これは構造化した200テンプレートの検査である。

実開発3問の各10秒では改善なし。rococoは137個、30nは548個を緩めたが両方局所不能、co-100は2399個を緩めて局所iteration上限、主解は全てなし。主問題の下界は両設定同じ。近接行の数だけで選ぶ5%緩和版は不採用として保存する。次案は局所LPの不能方向に現れる固定変数をヒントとして優先する別branchで検査し、そのヒントを元問題の証明・枝刈りには使わない。
