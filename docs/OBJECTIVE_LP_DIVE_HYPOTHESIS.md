# 既存主解を改善する局所LP diving

親PR104。MIP_OBJECTIVE_LP_DIVE既定false。既存のLP divingを変えず、最初のroot LPで主解が既にある場合に別の局所探索を行う。正規化した現主解より8e-8*(1+abs(value))だけ良い目的値を求める行を局所Modelへ追加し、近い側への分枝と逆側1回の試行を繰り返す。既に整数の他変数を一括固定せず、選択変数の境界だけを順に狭める。自作Rust LPを使い、既存solverへ委譲しない。

追加行は主解探索だけの制約で、不能・下界・擬似コスト・局所基底は主探索へ返さない。返す点は元モデルの制約/境界/整数性と目的値信頼性を確認し、改善した点だけを採用。全体5%、最大1秒、最大256局所LPの枠。既存phaseより後、主解probeより前。再帰するsubsolveでは無効化する。名前別条件なし。未知の入力に通用する主解品質改善が仮説で、採否未定。
